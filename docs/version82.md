# 版82：はじめの画面・編成の画面・プロフィール（2026-10-20）

指示書「既存ゲームの全面改善・新ロビーUI・演出付きガチャ実装プロンプト」の2回め（13章・9章・4章）。ユーザー「クォリティをさらにあげて、作業を先にすすめて」。

## 1. できたこと

### はじめの画面（`scripts/flow/start_ui.gd`。flow_logic の start）
- URLを開くと：タイトル → **ログインしていなければ**「あたらしく アカウントを つくる／ログイン／ログインせずに あそぶ」。うしろに3Dのロビー（キャラ4人）、光る「BIG BUSTERS」。
- **ログインずみなら、この画面を出さずにロビーへ**（毎回えらばなくてよい。仮の決め）。
- 「ログインせずに あそぶ」：きろくは この端末のブラウザの中だけ・消すと消える・あとからアカウントを作れば引きつげる、と説明してから。
- ブラウザでない所（テスト・アプリ2）は、今までどおりロビーへ直接（`start_offline` で切りかえ）。

### アカウントを作る（`web/head/30_account.js`。ブラウザ側の本物の入力欄）
- 入力：**ID（「じどうで つくる」ボタン。最初から自動の案が入っている）・パスワード・もういちどパスワード・なまえ**。名前の下に、指示書の注意書き（本名・住所・電話番号…）をそのまま。
- 断る：パスワードが合わない・かんたんすぎる・**IDの形がちがう・IDがもう使われている**・なまえがない。
- 作れたら：IDと復旧コードを見せて、「ロビーへ すすむ」。ログインしたまま、ロビーへ。
- ID の形：**英大文字と数字の10もじ（まぎらわしい 0 1 O I はのぞく）、または数字だけ9けたまで**。いまの Firebase のルールのまま使える形にした（ルールは変えていない）。同じIDは、サーバーのルールでも断られる。
- 入力欄の見た目を、ゲームに合わせた（暗いガラス・オレンジのボタン・まるい入力欄）。なまえを かえる時にも注意書き。
- パスワードは、今までどおり Firebase の認証にまかせる（ゲームの中にも、ブラウザの保存にも、そのまま残さない）。

### 編成の画面（`scripts/flow/formation_ui.gd`）
- **上：4つの枠**（メイン＋なかま1〜3。顔の絵・名前・役の色）。選んでいる枠は金色に光る。
- **まんなか：くわしい情報**：顔・レア度（色の札と星）・名前・役・持っている／いない・**装備の2枠（まだ空）**・説明・能力5つ（たいりょく・こうげき・ぼうぎょ・はやさ・とどく。バーつき）・技（通常攻撃・スキル（Y）・スキル（X）・必殺技・覚醒能力）・「メインに セット」。
- **下：キャラの一覧**（顔の絵のカード。レア度の札・編成中の札・持っていないキャラは暗くして かぎと「みしょじ」）。画面の幅で列の数が変わる（縦は4列）。
- 入れかえ：**枠をタップ → 別の枠をタップで入れかえ**／**枠をタップ → キャラをタップで、その枠に入れる**／キャラをタップだけなら、くわしい情報。同じキャラは2人にならない（いれば入れかわる）。持っていないキャラは入れられない。

### 持っているキャラ（`scripts/flow/roster.gd`・`data/character_profiles.json`）
- はじめは **剣士・ファイター・ガンナー・エンジェル**（ユーザー決定）。残り5人は、版83のガチャで出る。
- 前から遊んでいる人は、そのとき使っていたメインのキャラも持っている（いきなり使えなくならないように）。
- 編成は、持っているキャラだけ・同じキャラは1回・4人に、自動でなおす。
- レア度（仮）：N＝ファイター・ガンナー／R＝剣士・アーマー・エンジェル／SR＝スピード・ボンバー／SSR＝魔法使い・おもちゃの兵隊。説明・防御・覚醒能力も仮（**防御と覚醒能力は、まだ戦いには使っていない**と画面にも書いた）。

### プロフィール（`scripts/flow/profile_ui.gd`。前の「アカウント」の画面）
- 大きなアイコン（金の輪）・名前・ID（ゲストは「きろくは この端末だけ」）・**「アイコンを えらぶ」**（持っているキャラの顔から）。えらぶとロビーの左上も変わる。
- その下は今までのボタン（ログインを つくる・ログイン・パスワードを わすれた／なまえを かえる・ログアウト）と画質。

### 見た目をそろえた
- メニューの画面の背景を、紺のグラデーションに。ふつうのボタン（もどる・つぎへ など）を、すべてガラスの見た目と押した時の動きに（`game_flow.gd` の `_make_button`）。
- 顔の絵は、一度作ると端末に保存する（`user://portraits/`。2回目からすぐ出て、重くない）。

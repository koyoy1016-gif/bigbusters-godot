# 版85：音楽と効果音（2026-10-20）

指示書「既存ゲームの全面改善…」の音の章。音楽も効果音も、すべて計算で作った自作の音（録音や他の作品の音は使っていない。CC0扱い。`assets/LICENSES.md`）。

## 1. 音楽（`tools/make_music.py` → `assets/audio/bgm/*.ogg`）
| 曲 | 使う所 | 長さ | 中身 |
|---|---|---|---|
| lobby | タイトル・ロビー・編成・ガチャ・プロフィール | 40秒ループ | 96BPM。エレピの和音・やわらかいベース・軽い太鼓。前半は笛、後半はベルの旋律（夕方の街） |
| battle | 戦い（ボスの第1形態） | 26秒ループ | 148BPM・ニ短調。8分のベース・裏拍のパワーコード・16分のアルペジオ・金管の旋律・おかず |
| awake | ボスの覚醒のあと | 23秒ループ | 164BPM・ホ短調。歪んだベース・太鼓の追加・声のような和音 |
| win | 勝った時 | 4.6秒 | ファンファーレ（上がる金管→和音と鐘） |
| lose | 負けた時 | 4.6秒 | 下がる笛と、くらい和音 |

- ループの曲は、はみ出した余韻を曲の頭に足してあるので、つなぎ目で音がとぎれない。
- 曲の切りかえ（`scripts/audio/bgm.gd`）：再生口を2つ使い、前の曲を小さくしながら次の曲を大きくする（クロスフェード 1.2秒）。
  - メニュー → 戦い：ロビーの曲は0.8秒で消え、戦いが始まった時に戦いの曲。
  - ボスが倒れた（第1形態の体力0）：音楽を一時的に14dB下げる → 覚醒した時に、雄たけびと一緒に覚醒の曲へ。
  - 勝ち・負け：短い曲。その途中でロビーにもどっても、短い曲が終わってからロビーの曲（とちゅうで切れない）。
  - 大きな効果音（雄たけび・必殺技・ガチャのSSRなど）の時は、音楽を少し下げて、もどす（ダッキング）。
- 数値は `data/bgm.json`（曲ごとの大きさ・ループ・フェードの秒・下げたあと戻る速さ・はじめの大きさ）。

## 2. 効果音（`tools/make_sfx.py` → `assets/audio/sfx/`、39個）
- ほぼ全部を作り直した。当たりは「キレ（高いぱしっ）」「芯（低いどすっ）」「中の音（ざくっ）」を重ねて、手ごたえを強くした。
- 新しい音：銃（ぱん）・大砲（どーん）・魔法を撃つ（ひゅいーん）・魔法が当たる（鐘の和音ときらきら）・爆発・花火（ぽんっ）・回復（上がる3音）・強い当たり（ずどん）・ボスの足音（ずしん）・覚醒の雄たけび・倒れた・起きた（上がるきらきら）・ガチャ（弓のきしみ・目もりの「こつ」・弦の「びゅん」・鬼を斬る・結果4種類）・コイン。
- 鳴らすたびに高さを少し変える（pitch_var。同じ音のくり返しが機械っぽくならない）。
- 0.45秒より長い音は Ogg（ファイルを小さく）。合計 約430KB。
- `data/sfx.json`：音ごとの大きさ・間かく・高さのゆれ・音楽を下げる量。`proj_sounds`：飛ぶ物（prop）ごとの撃つ音と当たる音（13種類すべて）。`battle`：AIの味方の音を小さくする量・遠いほど小さくする距離。

## 3. 戦いの中の音（`scripts/prototype/battle_audio.gd` 新規）
- 自分の攻撃：剣・拳は「斬る音」、銃・魔法・爆弾などは「撃つ音」（斬る音は重ねない）。当たると当たりの音。必殺技・impact のある技は「ずどん」も重ねる。
- 飛ぶ物は、当たった時に、その飛ぶ物の当たりの音（弾＝当たり、魔法＝きらきら、大砲・プレゼント＝爆発、花火＝ぽんっ）。回復の光が届くと回復の音。
- AIの味方の攻撃の音は 8dB 小さく、さらに遠いほど小さく（自分の音が聞きやすい）。
- ボスの足音：歩きの動き（walk_cycle_m の半分）ごとに1回。止まっている時・跳んでいる時は出さない。6m より遠いと小さくなり、34m で −15dB。
- 倒れた・起きた（版84の蘇生）に専用の音。覚醒の時は雄たけび。

## 4. せってい（プロフィールの画面）
- 「せってい」のカード（`scripts/flow/settings_ui.gd` 新規）：**おんがく**・**こうかおん**のすべりバー（0〜100%、5%きざみ）と、**がしつ**のボタン（前からのボタンをこのカードへ移した）。
- 左のアイコンを押すと、その音を消す／前の大きさにもどす（効果音はスピーカーに×が出る）。
- 効果音のバーを動かすと「ぽこっ」と鳴って、大きさが分かる。
- 決めた大きさは、この端末に保存（`user://audio_settings.json`。クラウドのセーブには入れない）。はじめは音楽80%・効果音100%。
- プロフィールの画面は、はみ出したら縦にスクロールできるようにした（横画面でも入る）。
- アイコンの絵（`scripts/ui/lobby_icon.gd`）に、音符・スピーカー・きらり を足した。

## 6. 未確認・まだのこと
- **音そのものは、耳で聞いて確かめていない**（作業の場所に音を聞く手段がない）。波形と周波数の図、音の大きさ（ピーク・平均）、ループのつなぎ目は数字で確かめた。実機で聞いて、大きさのつり合いや好みを直す必要がある（数値は data の JSON で変えられる）。
- ブラウザ（iPhone Safari）での音の動き：Godot のブラウザ版は、音を「サンプル」として先に全部ほどいて持つので、曲を切りかえる時の大きさの変化・ループ・高さの変化が、実機でも同じに動くかは未確認。
- メモリ：ブラウザでは曲を全部ほどいて持つため、5曲で約25MBを使う見こみ（目標150MB前後の中）。実機で測る。
- 通信中のほかの人の攻撃の音は、まだ出さない（今までどおり）。

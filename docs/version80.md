## 1. できたこと

### 見つけた不具合（版79まで）
- **飛んでいる間、飛ぶ物の大きさ（scale）が効いていなかった**。毎コマ向きを入れ直す時（`battle_skills.gd` の `_update_projs`）に大きさが1にもどっていた。プレゼント・ぬいぐるみ・魔法の玉が、データの数字より小さく見えていた原因。向きを入れたあとに大きさをかけ直すようにした。
- ボスの「のけぞり」は、つづけて当たると最初の1発だけだった（連射では反応が見えなかった）。1発ごとにのけぞるようにした。

### ガンナー：全部「弾」に（`tools/make_char_actions.py` の gunner・`tools/make_props.py` の bullet・cannon_shell）
- ビームをやめた。A（左右1発ずつ）・Y（後ろへ跳びながら3発）・X「ダブル連射」（左右かわるがわる12発）・必殺「フルバースト」（大きな砲弾10発。当たった所で小さな爆発）。
- 弾の形：金色の胴・赤だいだいのとがった先・おしりの帯・まわりの薄い光・**短い尾**（版79は尾が長く、ビームに見えた）。大きさ 2.4倍（胴が約0.8m）。速さ 48 → 24 m/秒（画面に長く見える）。飛んだ道に金の粒（尾）が残る。
- 銃口の光を大きく（0.9 → 1.4倍）。
- ダメージの合計は版79と同じ（X：0.5×12＝6.0、必殺：2.3×10＝23.0）。X・必殺は前はビームで「つらぬく」当たりだったが、いまは弾1発ずつ、ねらった敵に当たる。

### 魔法使い
- 魔法の玉 1.1 → 2.1倍、大きな玉（Y）1.3 → 2.3倍。くるくる回り、むらさきの光の粒を引く。速さを少し落とした（17 → 14、12 → 11 m/秒）。
- 当たった所に「魔法の見た目」：むらさきの光の玉・足もとに広がる輪・一瞬光る魔法陣・のぼる星（`battle_skills.gd` の `_spark` の magic）。
- ダメージの範囲・量は変えていない。

### ボンバー（プレゼント）
- プレゼント 1.0 → 2.2倍（約0.75m）、大きなプレゼント（X）2.5倍、花火の玉 1.6 → 2.6倍。回転をゆっくりにして形が分かるように。導火線の金の粒を引く。
- 投げた手が、きらっと光る。A のプレゼントの爆発にも紙ふぶき（プレゼントと分かるように）。
- 落ちたびっくりプレゼント（Y・X）の箱も、飛んできた大きさに合わせた（約1.1m）。

### おもちゃの兵隊の「人形」
- 呼び出す**ぬいぐるみ**（くま・うさぎ）を、背の高さ 1.6m にそろえた（版79は約0.4〜0.6m。約3〜4倍）。ふつうのキャラ（約3.4m）の約半分。
  - 指示の「2〜3倍、ふつうのキャラの約半分」の両方に合うのはぬいぐるみだった。**小さい兵隊（X・必殺）は、すでにふつうのキャラの約半分**（測った）なので変えていない。
- 投げるぬいぐるみ（A）も 0.55 → 1.4倍。
- エンジェルのハートの矢 1.4 → 2.0倍、いやしの光 2.2倍（光の粒を引く）。

### 当たった時（全キャラ共通。`battle_skills.gd` の `_spark`・`skill_fx.gd` の spark・`data/prototype_stick.json` の `hit_fx`）
- 火花を 1.5倍に。**白い一瞬の光**（0.1秒で消える）と、**撃った人の方を向く衝撃の輪**を足した。
- **ボス**：1発ごとに白く光る（当たった直後 0.07秒だけ。連射でも点めつして、1発ずつ分かる）。1発ごとに体を小さくのけぞらせる（約0.15秒ですぐ戻る。歩き・攻撃は止めない）。`data/boss_model.json` の `flinch_decay_per_sec`・`flash_energy`。
- 外れた弾は、今までどおり、けむりを出して消える（当たった時だけ火花・光・数字）。

## 2. 見た目の変更
- **背を高く**：「縦をもっと大きく」は答えが「不明」だったので、全員の背を少し高くした（剣士より低かった人は剣士と同じ以上に）。ファイター1.06・スピードファイター1.1・ガンナー1.07・ボンバー1.04・魔法使い1.0・アーマー0.98・おもちゃの兵隊1.07・エンジェル1.0（剣士＝1.0）。ちがう意味だったら教えてほしい。
- **エンジェルの仮面**：目をおおう白い仮面（金のふち、両はしに小さな羽）。
- **ぬいぐるみ部隊**：くま（茶・青リボン）、うさぎ（白・ピンク）、くま（明るい茶・赤リボン）の3種類。ボスへ跳ねながら歩いて、たたく。

## 3. 技の考え方（数字は `docs/char-actions-v78.md`）
- 剣士の基準（22.5・58.5・90・346.5）は変えない。必殺技は、剣士（346.5）に近い300〜345にそろえた（遠くから安全に撃てるガンナー・エンジェルは少し低め）。
- 近くで戦う人（ファイター・アーマー）は1回が強い／遠くから撃てる人（ガンナー・魔法使い・エンジェル）は1回が弱い。
- 効果の技（超高速・ドーム・時間停止・回復・蘇生・呼び出し）は、待ち時間を長くした（15〜25秒）。
- 指定を守ったこと：20連パンチは1発ずつ計算／超高速1.75倍／ダブルビームは2本それぞれ当たる／ドームは敵を含めた全員の攻撃力50%低下・被ダメージ50%軽減（ボスへのダメージも、味方が受けるダメージも 0.25 倍）／ぬいぐるみは本体の攻撃力に足さない（同時7体まで）／回復に乱数・クリティカルなし／時間停止にはボスの耐性（20秒以内の2回目は半分）。

## 4. 動き（アニメ）
- 新しい素材は使えない（Blender・外のダウンロードができない）ため、剣士と同じ13この動きから作った。
- 「腕をねらった向きへ向ける（aim）」を作ったので、ビームを撃つ（両腕を前）、手を上げて時間を止める、盾を上にかかげてドームを張る、弓を引く、などを、その技の向きで作れるようにした。
- 武器（大砲・つえ・弓）は前腕に付け直した（手首の曲がりで向きが変わらないように）。
- 各キャラの4つの技の動きは、`tools/moves_sheet.sh` で並べて目で確かめた。

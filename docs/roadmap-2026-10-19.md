# これからの進め方（2026-10-19 19:50 版55のあと）

ユーザーの質問（19:47）への答え。次にやることの順番、ボスの攻撃の案、キャラ・建物を作る無料ソフト。

## 1. 順番の考え方
1. **戦いの面白さを先に固める**（数値・攻撃の種類）。ステージ・キャラ・建物は、戦いの形が決まってから作るほうが、作り直しが少ない
2. **増やす前に、土台を整理する**（コードの分割）。キャラ・ステージ・ボスを増やすほど、整理しないと直しにくくなる
3. **雰囲気（音・画面）**は小さな作業で、遊ぶ人の印象が大きく変わる
4. **量産**（味方キャラ → ステージと建物 → 2体目のボス）
5. **ご褒美の仕組み・公開準備**は、遊びが固まってから

## 2. 優先順位（大きさ：小＝半日ほど、中＝1〜2日、大＝数日以上）

## 3. ボスの攻撃パターン（すべて案。確定ではない）

### いまあるもの
| 姿 | 攻撃 | よけ方 |
|---|---|---|
| 平常 | バットの横振り（右うしろ→左前、腰の高さ） | ジャンプ・うしろへ |
| 平常 | バットの縦振り（前へたたきつける帯） | 横へ |
| 平常 | 回転斬り（バットを横にして何回も回る） | 輪の外へ・ジャンプ |
| 平常・覚醒 | しっぽ回し（体のそばは安全） | 近づく・ジャンプ |
| 平常 | 歩きながら振る（3回） | 横へ回りこむ |
| 平常・覚醒 | つかみ投げ（1〜3秒、10回連打で逃げる） | 輪から出る・仲間が攻撃して助ける |
| 覚醒 | 酒の雨（空へまいて、上から降る） | 輪から出る |
| 覚醒 | 台風（腕を広げて回る） | 輪の外へ・ジャンプ |
| 覚醒・必殺 | 酒の大雨（全体に降る） | 輪から出つづける |
| 覚醒・必殺 | 大きな手のなぎはらい（端から端へ3回） | ジャンプ・帯の外へ |

### 足す案（選んでほしい）
| 案 | 内容 | 遊びのねらい |
|---|---|---|
| A 突進 | まっすぐ体当たり。壁や柱にぶつかると、しばらく動けない（チャンス） | ステージの柱が役に立つ |
| B 跳んでたたきつけ | 高く跳んで落ちる。衝撃の輪が外へ広がる | 輪のすきまをジャンプ |

攻撃を決めるときの約束：①必ず予告がある ②よけ方が1つ以上ある ③攻撃のあとに「すき」がある。

## 4. キャラ・ボス・建物を作るソフト（無料）

**いまの作り方で作れるもの**：人型は、剣士と同じ体（MPFB）＋小物＋動き素材で作れる。人型以外も、版49〜53の鬼のように「形をコードで組む」ことはできるが、細かい形には向かない。**Godot は、骨があれば人型以外も動かせる**。

| ソフト | 何に使う | むずかしさ | 費用・権利 |
|---|---|---|---|
| Blender | 何でも（人型以外の生き物・建物・小物・骨と動き）。いちばん自由 | むずかしい | 無料（GPL。作った物は自由に使える） |
| Blockbench | ローポリの生き物・小物・建物。色ぬり・骨・動きも付けられる | かんたん | 無料・オープンソース。Godot 用の書き出し（glTF）は未確認 |
| MPFB（Blender の追加機能） | 人型の体（剣士はこれで作った） | ふつう | 無料 |
| Mixamo | 人型に、自動で骨と動きを付ける | かんたん | 無料（Adobe ID が要る）。人型（二足）だけ。ゲームに使ってよい |
| Quaternius（素材） | 動きつきのモンスター・動物など | ― | CC0（自由に使える）。いまの動き素材もここ |
| Kenney（素材） | 建物・町・小物のキット（Godot で読める形式あり） | ― | CC0（自由に使える） |

おすすめの進め方：
1. まず素材集（Quaternius・Kenney、CC0）で、ステージと2体目のボスの「仮」を作り、遊びを確かめる
2. 気に入った方向が決まったら、Blockbench（かんたん）か Blender（本格的）で、自作に置きかえる
3. デザイン画（AIの絵でよい）をもらえれば、Claude が「素材の組み合わせ」や「コードで組む形」で作るところまでは進められる

建物・物を作るときの約束（重さ）：面の数を少なく（ローポリ）、同じ物はまとめて描く（MultiMesh）、画像は小さく（512以下）。

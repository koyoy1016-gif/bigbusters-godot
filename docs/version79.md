## 1. できたこと

### ターゲットロック（`scripts/combat/target_lock.gd`・`stick_prototype.gd`・`battle_hud.gd`）
- 敵をタップすると、その敵をロック。敵の中心に、回る赤い照準（4つの弧・目盛り・中心の点。ロックした時に小さくなりながら出る。遠いと少しうすい）。
- 同じ敵をもう一度タップで外す。敵が倒れた・消えた・戦いが終わると外れる（サブ敵が倒れたら、ボスを選び直す）。
- ロック中は、近くの攻撃・遠くの攻撃・必殺技のすべてが、その敵の方へ向く。近くの攻撃で少し遠い時は、まず走って近づいてから出す（0.6秒・4m まで。もっと遠いと近づかない）。
- 味方をタップすると、回復の光の送り先になる（緑の輪）。もう一度タップで外す。

### 飛ぶ物（`scripts/combat/projectiles.gd`・`battle_skills.gd`。見た目の小物は `data/props.json`・`tools/make_props.py`）
- 銃弾・魔法の玉・プレゼント・花火・ぬいぐるみ・ハートの矢・いん石・回復の光は、発射口（つえの先・砲口・手・弓）から出て飛び、**当たった時にダメージ**（ダメージの量は撃つ時に `damage.gd` で決める）。
- 銃弾：銃口の光・光る弾（尾）・当たった所の火花。魔法：ゆるく追いかける（1秒に90〜140度まで曲がる）。
- 爆弾（プレゼント・花火）：放物線で、ねらった敵の手前の足もとに落ちる。爆発の半径＝ダメージの範囲。
- メテオ：敵の上・うしろの空の高い所（16m）から落ちる。

### 手ごたえ・カメラ
- 強い攻撃（Y・X のしめ・必殺技）が**当たった時だけ**、一瞬止める・画面のゆれ・カメラが少し寄る（hit の `impact`：[秒, ゆれ, 寄り]）。弱い攻撃（A）ではゆれない。自分の技だけ（AI の技ではゆれない）。

### 動き（アニメ）の作り直し（`tools/make_char_actions.py` の `pose_anim`・`scripts/characters/anim_compose.gd`）
- 技の動きは「姿勢（腕・脚・胸のひねり・頭）」を時刻に並べて作った。どの技も「ため → 打つ → 止め → もどり」。
- **足が床につく**：毎コマ、足首の高さを計算して腰の高さを決め、両足で立つ姿勢では、もう片方の脚のひざを曲げて床に下ろす（2本の骨の IK）。けり・片足立ちは、立っている足だけ。跳ぶ・うく動きは上げる量を書く。テストで、A の間の足のずれが、骨の長さの単位で 0.02 未満（脚の長さの約2%）を確かめた。
- 胸のひねりの向きを確かめて直した（左ジャブは左肩が前、右ストレート・棍棒・投げは右肩が前）。
- 歩く（スティックを少しだけ倒す）・勝った（両手を上げて跳ぶ。自分と味方）・負けた（ひざをつく。用意だけ。下の「まだのこと」）を全員に足した。
- 止まる・曲がる・走り出す時に、体が速さの変わる向きへ少しかたむく（最大8度。もどる）。
- 小さい兵隊の動き：気をつけ・行進（ひざを上げる）・かまえて撃つ（反動）。

### 女性キャラ（魔法使い・エンジェル）
- 骨格から女性に：肩はば・鎖骨を細く、骨盤を広く、腕・手・足を小さく、もも・すねを少し長く、首を少し長く（`tools/make_looks.py` の `FEMALE_BONES`）。顔（目・まゆ・くちびる）と体の形も女性に。

### 重さへの配慮
- 作った動きは、形（モデル）ごとに覚えて使い回す（`character_view.gd` の `_built_cache`）。兵隊を何度呼んでも作り直さない。
- 兵隊の動きは、戦いの始めに前もって作る（おもちゃの兵隊がチームにいる時だけ）。兵隊の形は軽くした（約1万三角形）。

## 4. まだのこと・未確認（できたことにしていない）
- **Blender は使っていない**（通信が止められている）。形と動きは、Godot のコードで作った。
- **iPhone 実機**の重さ・見やすさは未確認（兵隊・ぬいぐるみが最大12体・膜・飛ぶ物が多い時）。

- **負けた動き**（ひざをつく）は作ったが、負ける時は全員がダウンしているので、いまは「たおれた」動きのまま。
- **止まる・曲がるの専用の動き**はない（体のかたむきで表した）。よける・やられ・ふっ飛びは、今までの動き（Roll・Hit・Death）のまま。

- 技の名前は仮。

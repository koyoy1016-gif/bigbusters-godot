# 作風（見た目の決まり）  2026-10-19 決定（Claude。ユーザーの確認は未）

## 方針：「はっきりした色と線のスタイライズ」
写真のような写実は目指さない（スマホのブラウザで重く、容量も足りない）。
**アニメ寄りの立体**（ベタ塗りに近い陰影＋輪郭線＋縁の光＋ざらっとした質感）で、全キャラ・全ボス・全ステージをそろえる。

## 決まり
1. **色**：1キャラにつき、主役の色1つ＋白か黒の補助色1つ＋差し色1つ（侍：藍＋白＋赤）。彩度は高めにする。
2. **陰影**：ふつうの陰影ではなく、段のついた陰影（トゥーン）にする（`diffuse_mode`／`specular_mode` を TOON）。
3. **輪郭線**：黒に近い濃い色の線を、モデルのまわりに出す（裏返した殻方式）。画質「高」のみ。「低」は出さない。
4. **縁の光**：体のふちを、少し明るくする（リムライト）。画質「低」でも出す（軽い）。
5. **質感**：256×256以下の、つなぎ目のない模様（布・金属・肌）を、色に重ねる。模様は弱め（明るさ ±15% 程度）。
6. **形**：部品を重ねて「層」を作る（鎧の板、肩当て、ひも）。大きな形が先、細部は後。シルエットだけで誰か分かるようにする。
7. **ボス**：味方より大きな形と、はっきりした1色。目と口は大きく、怖いより「憎めない」寄り。
8. 他社の作品に似せない。素材は自作（`tools/make_textures.py` が作る。CC0扱い）。

## 数値
`data/art_style.json`（リム、輪郭線の太さと色、質感の名前と細かさ）。画質のスイッチは `data/quality.json` の `outline`。

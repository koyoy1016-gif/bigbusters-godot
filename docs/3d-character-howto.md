# 3Dキャラ（剣士）を無料で作る手順（2026-10-18）

目標：主人公の剣士1体の `.glb` を作って、Claude に渡す。道具はすべて無料（0円）。リアル路線。
面の数は 15,000面以下（味方1体の上限）、貼り絵（テクスチャ）は 512×512 以下（CLAUDE.md ルール8）。

## 0. 先に知っておくこと
- 使う道具：Blender（3Dソフト・無料）＋ MPFB（Blender用の人体づくりの追加機能・無料）。
- 作った人体の、基本の部品（体の形・肌など）は CC0（自由に使える）。第三者が作った服・髪などは、それぞれのライセンスが違うことがある → 使った部品は、名前とライセンスを Claude に伝える（`assets/LICENSES.md` に記録する）。
- 未確認：下の画面の名前（ボタンの名前）は、版によって少し違う場合がある。違っていたら、画面の写真を送ってほしい。
- Mixamo（Adobe）は使わない。元ファイルの再配布禁止で、公開リポジトリに入れられない。

## 1. Blender を入れる
1. ブラウザで blender.org を開く → Download → Windows 版（インストーラー）→ インストール。
2. 版：MPFB は Blender 4.2 LTS 以降が必要。公式の最新の安定版か、4.2 LTS 以降を入れる。
3. 起動して、最初の画面（スプラッシュ）を閉じる。

## 2. MPFB を入れる
1. Blender の上のメニュー「Edit」→「Preferences」→ 左の「Get Extensions」。
2. 検索で「MPFB」→「Install」。（ネットへの接続を許可するか聞かれたら、許可する）
3. 3Dの画面の右上の小さな矢印（<）か、キーボードの N を押す → 右にタブが出る。その中に「MPFB」のタブが出れば成功。
4. 手動の方法：extensions.blender.org の MPFB のページから zip をダウンロード（約44MB）→ Preferences →「Install from Disk」。

## 3. 部品（服・髪・肌など）をダウンロード
- MPFB のタブの中に、アセット（部品）のダウンロードの項目がある（名前は未確認。「Assets」「Download assets」などと出る）。基本の部品のセット（system assets）を入れる。
- 見つからなければ、MPFBのタブの写真を送ってほしい。

## 4. 人体を作る
1. MPFB →「New human」（新しい人）。男性の標準から始める。
2. 体型を整える（スライダー）：
   - 身長を高めに。頭を小さめに（7〜8等身）。
   - 腰（ウエスト）を細く。肩幅を少し広く。
   - 筋肉は中くらい。体重は軽め。
3. 肌：MPFB の「Skin」から、標準の肌を選ぶ。
4. 顔（目・眉・まつげ）：標準を入れる。

## 5. 骨（リグ）を入れる
- MPFB →「Rigging」→「Add rig」→ ゲームエンジン向けの骨（「Game engine」などの名前）を選ぶ（未確認）。
- 歩く・走る・斬るの動きは、Quaternius のCC0のアニメ集を、Godot の中で、この骨に合わせて取り込む（Godot側の設定は Claude が行う）。

## 6. 服を着せる（忍者っぽく）
- 部品の服（長袖・長ズボン・ブーツ・手袋など）を、黒や濃い色にして着せる。
- 頭巾・口元の布・剣・帯は、部品にないはず。Claude が Blender用のスクリプト（Python）を書く。あなたは、Blender の「Scripting」タブに貼って、実行ボタンを押すだけ。

## 7. 軽くする（面の数を 15,000 以下に）
- 画面右上の「Overlays」→「Statistics」にチェック → 「Triangles（三角形の数）」を見る。
- 多すぎるときは、MPFB の「Proxies（軽い版の体）」を選ぶか、Blender の「Decimate」で減らす。
- 貼り絵は、512×512 以下にする（Claude が確認して、必要なら縮める）。

## 8. 書き出す
1. 体と服を全部選ぶ（骨も）。
2. 「File」→「Export」→「glTF 2.0 (.glb/.gltf)」。
3. 設定：Format＝「glTF Binary (.glb)」／Include＝「Selected Objects」にチェック／Mesh＝「Apply Modifiers」にチェック／Animation は、オフ。
4. ファイル名：`hero_swordsman.glb`。

## 9. Claude に渡す
- このチャットに、`hero_swordsman.glb` を添付する。使った部品の名前も書く。
- Claude が、`assets/models/` に入れ、`data/characters.json` に登録し、骨・アニメの対応を設定して、画面で表示を確認する。

## 目安の時間
- 初めてなら、1体目は 3〜6時間くらい（操作を覚える時間を含む）。2体目からは、同じ体を使って、服・髪・色・持ち物を変えれば、1体あたり 30〜60分が目安（予測）。

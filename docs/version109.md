# 版109：BIGBLAST・はじめの画面・役職名とラベル・結果と再戦の準備（2026-10-23）

ユーザーの指示書「BIGBLAST — 既存ゲーム改修・UI刷新・軽量化」を6回に分けた1回め（ユーザー了承：109名前と流れ→110ボタンと回避→111キャラの技→112演出→113画面の見た目→114軽量化）。

## したこと
- **ゲームの名前を BIGBLAST に**：はじめの画面の名前（`data/game_flow.json` の start_title）・プロジェクトの名前（`project.godot`。ブラウザのタブの名前）。ブラウザの保存（user:// ＝ /userfs）は名前に関係しないので、記録は消えない。
- **起動はアカウント選択の画面から**（TOKYO の読み込み画面はやめた）：`start_ui.gd`
  - ログインの準備ができるまでは「じゅんびちゅう…」だけ（点が動く）。ボタンは出さない・押せない（`flow_logic.start_ready`。4秒待っても準備ができなければ、ゲストで遊べるようにボタンを出す）
  - ログインずみ：「つづける（なまえ）」と「べつの アカウントで ログイン」。前のように勝手にロビーへは進まない（自分で選ぶ）
  - ログインしていない：作る・ログイン・ゲスト（今まで通り）。ログインの仕組みがない所（テスト・アプリ2）：「あそぶ」だけ
- **役職名の変更**（表示だけ。内部の id・セーブはそのまま）：けんし→剣士・はやて→瞬・こぶし→拳士・じゅうし→銃士・ばくだん→奇術師・まほう→魔法師・たて→守護士・よびだし→兵隊・いやし→介護士（`data/characters.json` の name。前の名前は old_name）
- **役職のラベル**（`scripts/ui/role_label.gd`）：斜めの黒い板・役職の色のふち・うすい発光・斜めのしま・上の金属っぽい光・太い字（縁どり）。色だけでなく必ず字。長い名前は字を小さくして入れる。描き直すのは中身が変わった時だけ。
  - 役職の色（`role_color`）：剣士 金・瞬 水色・拳士 赤・銃士 オレンジ・奇術師 ピンク・魔法師 むらさき・守護士 青・兵隊 黄緑・介護士 緑
  - 使っている所：ロビーのキャラの名前・編成のくわしい情報・結果の画面・再戦の準備。戦いの中の必殺技の帯・ハイライトのベストアタッカー・なかまの名前も役職名（`role_name_of`）
  - もとの「ファイター・シューター・ガーディアン・サポート」は、タイプとして小さな札に残した
- **コイン**：勝ち50・負け25（前は負け10）。1試合に1回だけ（`_match_serial`：結果をもう一度出しても・ハイライトから戻っても・再戦を押しても、ふえない）
- **結果の画面**（`scripts/flow/result_ui.gd`）：VICTORY／DEFEAT を大きく・+50 COINS／+25 COINS・使ったキャラの役職ラベル・「ハイライトを 見る」（記録がある時だけ）・再戦・ロビーへ もどる
- **流れ**：戦い → 結果 →（ハイライト → 結果）／再戦 → **再戦の準備**（チームの役職ラベル・大きな START）→ START で新しい試合／ロビー
  - 再戦を押しただけでは始まらない。1人：START で戦いを作り直してから始める（前の試合の物は残らない）。通信中：START＝再戦の投票（全員が押したら、いちばん若い枠が始める。前と同じしくみ）
- 不具合の直し：敵が見えない時に、近くの攻撃の火花の場所を計算すると止まっていた（`projectiles.gd` の surface_point）

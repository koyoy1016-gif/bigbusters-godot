# 仕様書 v2（2アプリ構成）

最終更新：2026-10-17
v1からの変更：アプリを2つに分けた（友達用／収益化用）。収益化用は買い切りを想定。

---

## 1. 全体像

| | アプリ1（友達用） | アプリ2（収益化用） |
|---|---|---|
| 目的 | 友達20〜30人と遊ぶ | ストアで公開し、買い切りで収益化を目指す |
| 遊び方 | 合言葉の部屋で最大4人（足りない分はAI） | 1人＋AIの仲間3人 |
| 通信・フレンド | あり（Firebase） | なし |
| セーブ | あり（アカウント方式） | あり（端末内保存を推奨。下の4章） |
| 公開先 | GitHub Pages（無料） | Android先行、iPhoneは後（下の5章） |
| 目標時期 | MUST機能は来週 | 数週間〜数か月 |

### 作り方の方針
- 戦闘・キャラ・ダメージ計算などの**共通の土台を1つ**作る。
- 通信（Firebase）の部分だけを、アプリ1に付け、アプリ2では外す。
- 土台は同じGodotプロジェクトで作る。分けるのは、後でストア公開の準備をするとき。
- Firebaseのプロジェクトは、アプリ1専用の新しいものを使う（アプリ2とは混ぜない）。

---

## 2. 共通の土台

- コンセプト：**4人で1体の大型妖怪を倒す**（変えない部分）
- キャラクター：4体（仮の名前A〜Dで始める）
- 大型妖怪：1体から始める。攻撃パターンは2〜3種類
- ダメージ計算（仮）：攻撃力 × 技の倍率 ÷（防御 + 基準値）
  - 計算は**1つの関数にまとめる**。ステージごとに別の計算を作らない
  - 数値は、キャラ・技ごとにデータファイル（JSON）に分けて置く
- 操作（スマホ）：左に仮想ジョイスティック、右に通常攻撃・スキル・必殺。横画面固定
- 他社の作品と似ないよう、キャラ、技名、台詞、音、絵は**すべて自作**にする

---

## 3. アプリ1（友達用）

v1の仕様を引き継ぐ。

| 優先度 | 機能 |
|---|---|
| MUST（来週） | 合言葉（4桁）で部屋に入る、AIで足りない人数を補う、接続状態の表示、自動で再接続 |
| SHOULD | アカウント登録（ゲームがIDを自動発行、本人がパスワード設定）、フレンドコード（8文字）で追加、オンライン表示、招待 |
| LATER | ステージを4〜5つに増やす、キャラの3Dモデル、解放条件、ホストの交代 |

### 通信
- アカウント・フレンド：Firestore
- 対戦中の同期・オンライン表示：Realtime Database
- 部屋を作った人（ホスト）がゲームの状態を管理し、ほかの人に送る
- 切れたとき：「再接続中」と表示して自動で戻る。戻れなければAIが代わりに操作する
- Firebaseは無料プラン（Spark）のまま使う。Blazeには変更しない

---

## 4. アプリ2（収益化用）

### 遊びの形
- 1人で操作し、残り3人はAI
- 通信なし、フレンドなし、招待なし
- ステージは、最初は1つ（無料体験版になる）。反応を見て4〜5つに増やす（買い切りで解放される分）
- 無料の1ステージ目で「面白い」と思ってもらえることが、売上を左右する。最初のステージは特に丁寧に作る

### セーブ（推奨案）
- **端末の中に保存する**（ログインなし、サーバーなし）
  - 費用がかからず、個人情報を集めずに済む
  - 弱点：アプリを消したり、機種を変えたりすると、セーブが消える
- クラウドへのセーブ（機種変更でも引き継げる）は、必要になった時点で検討する

### 買い切りの形（決定）
- **無料体験版（1ステージ）＋全ステージ解放を買い切り**にする
- アプリは無料でダウンロードでき、1ステージ目だけ遊べる
- 「全ステージ解放」を1回購入すると、残りのステージが遊べる（月額や追加課金はなし）
- 購入したかどうかは、端末内のセーブに記録する
- 機種変更や再インストールのとき、購入を復元できるようにする（ストアの購入履歴から。実装方法は要確認）
- 値段は、ステージ数と遊べる時間が決まってから決める
- ガチャ（確率で出る有料アイテム）は入れない

#### 実装の注意（要確認）
- Godotでアプリ内課金を使うには、Android用のビルドテンプレートの導入と、課金用のプラグインが必要になる
- Google Playで有料の解放を売るための設定（支払い情報の登録など）は、今回確認できていない。公開の準備のときに、公式の手順で確認する
- 手数料は、Androidなら年100万ドルまで15%（デジタルの商品の売上）

## 5. 公開先と費用

| 公開先 | 費用 | 備考 |
|---|---|---|
| GitHub Pages＋Firebase（アプリ1） | 0円 | Firebaseの最新の無料枠は公式で確認する |
| Google Play（Android） | 登録料25ドル（1回のみ） | 手数料は年100万ドルまで15%。18歳以上。Windowsで作業できる |
| App Store（iPhone） | 年99ドル | 手数料は年100万ドル以下なら15%。**Macが必須** |
| Steam（PC） | 1作品100ドル | 売上1,000ドルで返金。手数料30%。PC用の操作調整が必要 |

- 円への換算は、為替しだい。
- Macの購入費・クラウドMacの費用は、金額を確認できていない。
- 音楽・効果音・3Dモデルの素材を買う場合は別にかかる。

### Androidで公開するときの条件（個人アカウント）
- 12人以上のテスターが、14日間続けて参加する非公開テストを行う（2023年11月13日以降に作ったアカウント）
- 友達20人にテスターを頼む

### 進める順番
1. アプリ1で友達に遊んでもらう（面白さの確認）
2. アプリ2を作る
3. Androidで公開する
4. 手応えがあれば、iPhone版を考える（Mac＋年99ドル）

## 6. 権利・規制・税金のチェックリスト

- [ ] キャラ、技名、台詞、音、絵は、すべて自作またはライセンスの明確なもの
- [ ] ゲームのタイトルが、他社の作品名と紛らわしくない（今の「BIGバスターズ」は見直す）
- [ ] 収益化の前に、著作権・商標に詳しい専門家に相談する
- [ ] ガチャは入れない（入れるなら、日本の規制を専門家か公式で確認してから）
- [ ] プライバシーポリシーの要否を、各ストアの条件で確認する
- [ ] 税金：会社員で、副業などの所得が年間20万円を超える場合は、所得税の確定申告が必要（住民税は別。自分の場合は税務署か税理士に確認）

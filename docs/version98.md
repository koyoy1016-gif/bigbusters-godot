# 版98：軽量化 A-2 夕方は街灯の光の輪を隠す（2026-10-20）

版96 の調査の 2 番（優先度 A）。

## 原因
- 街灯の下の地面の光の輪（透明の重ね描き・11m の四角 12こ）は、夕方（ふだん）は強さ 0.04 でほぼ見えないのに、毎コマ描いていた。

## したこと
- `scripts/stage/time_of_day.gd`：夜の割合が `time_of_day.pool_show_from`（0.02）より小さい間は、光の輪の形ごと隠す。覚醒で夜へ切りかえ始めると、すぐ（約0.15秒）出る。
- `scripts/stage/map_loader.gd`：光の輪の形を `light_pools` として渡す。
- `data/maps.json`：夕方の光の輪の強さ 0.04 → 0（隠すのと同じ見た目）。夜の強さ（0.3）・街灯の柱と光る頭は、そのまま。

## 結果（同じ場面で、光の輪を出す／隠すを切りかえて測った。tools/perf_battle_fixed.gd の ab。低・390×844・llvmpipe）
| 場所 | 出す | 隠す |
|---|---|---|
| まん中 | 描画 131・80.9 ms | 描画 130・79.7 ms |
| 奥の右はし | 描画 114・74.2 ms | 描画 113・66.9 ms |
| 手前の左はし | 描画 128・88.9 ms | 描画 127・91.2 ms |
描画の回数が1回へる。時間の差は 0〜7 ms で、ゆれ（±7 ms）と同じくらい＝**効果は小さい**（版96 の部品ごとの 7.8 ms は、ゆれをふくんだ数だった）。見えない物を描かないだけなので、そのまま入れた。

## テスト
- test_v98（6）：夕方は隠れる・強さ 0・街灯は出たまま・夜へ切りかえ始めてすぐ出る・夜の強さは同じ・夕方にもどるとまた隠れる。
- 全テスト：Godot 76本・Node 66件 合格。

※ 草案。未決のところは「未決」と書く。v3 は `bigbusters-design-v3.md`（試作の元になった仕様）。

## 1. ゲームの流れ（起動から）
1. URLを開く → 読み込み中 → **タイトル画面**（仮の題名「TOKYO」）
2. 自動で **ロビー** に移る
3. ロビーでできること：編成、装備、ガチャ（扱いは未決。下の「決めること」）、キャラのレベル、プレイヤーランク、ステージ選択、プレイボタン、通信（部屋）のボタン
4. ステージを選んでプレイ → **ボス戦**
5. 戦いのあと：**ハイライト（約10秒）**。戦闘中の約6秒の中で、最も多く攻撃した仲間のプレイを流す
6. 「次へ」→ **報酬** をもらう。同じ画面に「再戦」か「次へ」
7. 「次へ」を押すと「再戦」か「ロビー」。再戦は同じステージをもう一度。全員が再戦を選ばなければ、ロビーへ戻る（1人でも再戦を選ばなければロビー）

## 2. 画面の向き
- 横画面・縦画面の両方に対応する。**縦を先に作る**（決定）。試作は、縦横どちらでも動く（版10）

## 3. キャラクター
- **忍者のキャラをメイン**にする。リアルで精巧な3Dキャラ。剣を持ち、振れる。ウエストが細く、7〜8等身くらい。（最初に出した参考画像は、他社ゲームのキャラ。**そのまま似せることはしない**。キャラは完全に自作する）
- 種類の数：味方40体、ボス7体、ボス以外の敵20体（計67体）。**同時に出るのは**、味方最大4人＋ボス1体＋サブの敵10〜15体くらい（決定）
- 戦いに出る4人は、ロビーの編成で、40体の中から選ぶ（決定）
- Claudeが作ると、ドット絵のような3Dになる。外部のツールも使う（無料のものを優先）

## 4. 役割（4つ。仮）
| 役割 | 内容 |
|---|---|
| サポーター | 体力があり、味方を守る |
| リカバリー | 回復する |
| アタッカー | 攻撃がメイン |
| クイック | 速い |

## 5. ステージ
- 1ステージ目：リアルな渋谷のスクランブル交差点（2026-10-20 に北千住から変更。交差点のまわりのみ。容量のため）。街並みは再現するが、**看板やロゴは再現しない**（決定）
- 使う地図データ：国土交通省 PLATEAU（3D都市モデル）。調べた結果は、チャットの回答と `NOTES.md` を参照

## 6. やり込み（案）
- キャラの成長、装備、プレイヤーランク、称号（ボスを何回倒した、最大火力がいくつ、など）
- ガチャ：**遊んで貯めた無料コインだけで回す**。お金では回せない。確率は表示する（決定。CLAUDE.md のルール6を更新済み）

## 7. 決めること・調べること
- セーブデータ（成長・装備・ランク）をどこに置くか（Firebaseの匿名ログインだと、ブラウザのデータを消すと失われる）
- 3Dキャラの作り方（無料ツールの利用条件は、使う前に確認）
- 渋谷のデータの実際の大きさ・見た目（版88で確認：PLATEAU 渋谷区2025年度。docs/version88.md）
- リアルな7〜8等身の忍者を、スマホのブラウザで、同時に約16体動かせるか（1体あたりの面の数の予算を、実機で測って決める）

- 出したいタイプ（9種。どれとどれを統合するか、総合的な呼び名は、今後決める）：

# ゲーム設計 v4（草案）— ユーザーの回答をまとめたもの（2026-10-18）

※ 草案。未決のところは「未決」と書く。v3 は `bigbusters-design-v3.md`（試作の元になった仕様）。

## 1. ゲームの流れ（起動から）
1. URLを開く → 読み込み中 → **タイトル画面**（仮の題名「TOKYO」）
2. 自動で **ロビー** に移る
3. ロビーでできること：編成、装備、ガチャ（扱いは未決。下の「決めること」）、キャラのレベル、プレイヤーランク、ステージ選択、プレイボタン、通信（部屋）のボタン
4. ステージを選んでプレイ → **ボス戦**
5. 戦いのあと：**ハイライト（約10秒）**。戦闘中の約6秒の中で、最も多く攻撃した仲間のプレイを流す
6. 「次へ」→ **報酬** をもらう。同じ画面に「再戦」か「次へ」
7. 「次へ」を押すと「再戦」か「ロビー」。再戦は同じステージをもう一度。全員が再戦を選ばなければ、ロビーへ戻る（1人でも再戦を選ばなければロビー）

## 2. 画面の向き
- 横画面・縦画面の両方に対応したい。両方が難しければ、まず縦画面（未決：どちらを先にするか）

## 3. キャラクター
- 3Dモデルで、凝ったキャラデザにしたい。丸みのある、デフォルメした3D（参考画像は、他社ゲームのキャラ。**そのまま似せることはしない**。「雰囲気」だけを参考にし、キャラは完全に自作する）
- 数の目安：味方40体、ボス7体、ボス以外の敵20体（計67体）。※同時に画面に出る数ではなく、種類の数かどうかは未確認
- Claudeが作ると、ドット絵のような3Dになる。外部のツールも使う（無料のものを優先）

## 4. 役割（4つ。仮）
| 役割 | 内容 |
|---|---|
| サポーター | 体力があり、味方を守る |
| リカバリー | 回復する |
| アタッカー | 攻撃がメイン |
| クイック | 速い |

## 7. 決めること・調べること

- 40体などの数は、種類の数か、同時に出る数か

- セーブデータ（成長・装備・ランク）をどこに置くか（Firebaseの匿名ログインだと、ブラウザのデータを消すと失われる）
- 縦横どちらを先にするか
- 3Dキャラの作り方（無料ツールの利用条件は、使う前に確認）

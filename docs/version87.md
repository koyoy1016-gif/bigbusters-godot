# 版87：編成の操作（スクロール・長押しで入れかえ・ロビーから編成へ）（2026-10-20）

ユーザーの指示：「下にスクロールできるようにして」「キャラ長押しでキャラを持って入れ替えられるように」「すでにいる枠に置かれたら入れ替わるように」「ロビーでキャラをタップするとそのキャラの変更画面（編成）のページに飛ぶように」。指示書の1・2・4。

## 1. スクロール（下まで見られる）
- 原因：編成の画面はスクロールの入れ物に入っていたが、中の部品（くわしい情報のパネル・顔の絵の入れ物・能力のバー・枠のボタンなど）が「押した指の動きを止める」設定だったため、**その上から指を動かしても、スクロールが動かなかった**（何もない所からだけ動いた）。
- 直し方：`scripts/ui/ui_kit.gd` に `scroll_friendly()` を足し、スクロールの中の部品を「下へ伝える」設定にした（すべりバー・文字の入力は、そのまま）。編成の画面と、スクロールのある画面（プロフィール・へや）で、作り直すたびにかける。
- 指でボタンを押したまま動かしてスクロールした時は、そのボタンは反応しない（Godot の決まり。テストで確認）。

## 2. 長押しで持って入れかえる（`scripts/flow/formation_ui.gd`）
- **枠のキャラ、または一覧のカードを 0.35秒 長押し**すると、キャラの絵が持ち上がって指につく（少し大きく・少しかたむき・影つき。指で隠れないよう、指の少し上）。元のカードはうすくなる。「こつ」と音、Android ではぶるっとふるえる。
- **枠の上に来ると、その枠が金色に光って大きくなる**。
- **枠の上で離すと、そのキャラが入る**。キャラが入っている枠なら、**2人が入れかわる**（一覧のキャラがチームにいる時も、枠どうしでも同じ）。「ぱきん」と音、枠がぽんとはずむ。
- **枠の外で離すと、元にもどる**（絵が元の所へもどって消える）。
- 長押しの前に指が 14px より動いたら、持ち上げない（ふつうのスクロール）。短く押して離すと、今までのタップ（枠を選ぶ・キャラの情報を見る）。
- 持っていないキャラは持ち上げられない（「まだ もっていません」のお知らせ）。
- 編成のデータ（メイン＝selected_character、なかま＝ai_picks）と保存は、今までと同じ所（`lobby_ui._apply_team`）で変えるので、ロビー・戦いとずれない。
- 数値は `data/game_flow.json`：`formation_long_press_sec` 0.35・`formation_drag_tolerance_px` 14・`formation_ghost_lift_px` 56。字：`formation_hint`・`formation_hint_drag`。

## 3. ロビーでキャラをタップ → 編成へ
- ロビーの3Dのキャラ（メインも、うしろの3人も）をタップすると、**そのキャラの枠を選んだ状態（入れかえ待ち）で編成の画面が開く**。一覧のキャラをタップするか、長押しで持ってくると、その枠のキャラが変わる。
- 前は、うしろのキャラをタップするとメインと入れかわっていた。それはやめた（横にスライドして回すのは、そのまま）。

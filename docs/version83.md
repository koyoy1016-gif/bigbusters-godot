# 版83：剣士を引っぱって敵を斬るガチャ（2026-10-20）

指示書「既存ゲームの全面改善・新ロビーUI・演出付きガチャ実装プロンプト」の10〜12章。CLAUDE.md ルール6（無料コインだけ・回す前に確率を表示・コンプガチャなし）を守る。

## 1. できたこと

### 画面（`scripts/flow/gacha_ui.gd`・`scripts/flow/gacha_stage.gd`）
- ロビーのいちばん下「ガチャ」から入る。3Dの場面：ロビーと同じ夕方の街を背景に、手前に剣士（うしろ姿）、前に**小鬼5体**（正面・左ななめ・右ななめ・奥に2体。1回ごとに少しずつ場所が変わる）。小鬼は、むらさきの体・金の角・目・黄色の帯。ゆらゆら待つ。
- **剣士をつかんで、うしろ（下）へ引いて、離す**（指でもマウスでも）。引いている間：剣士がうしろへ下がってためる・足もとの輪が赤く熱くなる・「ちから 94%」のバー・**飛ぶ道（金の帯）と終わりの輪（斬撃の広さ）**。右へ引くと左へ、左へ引くと右へ飛ぶ（50度まで）。少しだけ・上へ引いたら、やめる（払わない）。画面の外へ引いても、ちからは100%まで。
- 離すと：前へ飛び出す（剣士の必殺技の動き・残像）。**通った道の近くの小鬼**と、**終わりの斬撃（前の扇）の中の小鬼**を斬る。斬るたびに：三日月の斬撃・一瞬止まる・画面がゆれる・「ヒット」の音・小鬼が白く光って、ふっ飛んで回って消える・「斬った 2 / 5」がはずむ・**下の確率の札が、その場で上がる**。
- 結果：レア度ごとに演出を変えた。N：しずか／R：青い光の筋（少し）／SR：むらさきの光の筋と白い光／**SSR：虹の光の筋・強い白い光・特別な音**。顔の絵（レア度の色の光るふち）・名前・役・説明・レア度と星・**NEW!**・斬った敵の数・**使った確率**（当たったレア度を明るく）。もう持っていれば「もう もっている：コイン ＋40」。
- ボタン：「もう一度 引く（100コイン）」（コインを使うか確かめてから）・「ロビーへ」。
- 上：もどる・コイン・「1回 100コイン」（はじめは「はじめの1回は むりょう！」）・**「かくりつ」**。
- 斬っている間は、もどる・下のボタンを出さない（コインだけ減ることがないように）。ガチャから出ると、ガチャの3Dは消す。

### 確率と抽選（`scripts/flow/gacha_logic.gd`・`data/gacha.json`）
- 基本の確率（仮）：N 55% ／ R 30% ／ SR 12% ／ SSR 3%。
- 斬った数 k で変わる：重み ＝ 基本 ×（1 ＋ 係数 × k）（係数 N −0.12・R ＋0.08・SR ＋0.3・SSR ＋0.6）を、合計100%に割りなおす。**5体斬ると SSR 11.32%**（たくさん斬っても必ずではない）。
- レア度を決めてから、そのレア度のキャラの中から同じ確率で1人。N：ファイター・ガンナー／R：剣士・アーマー・エンジェル／SR：スピード・ボンバー／SSR：魔法使い・おもちゃの兵隊（レア度は版82の仮）。
- **表示と抽選は同じ関数**（`odds()`）。「かくりつ」の画面：斬った数（0〜5体）×レア度の表と、**キャラ1人ずつの確率**（0体のときと5体のとき）。回す前に見られる。
- 状態は「まつ → 引く → 飛ぶ → 結果 → まつ」の順だけ。払うのは離した時に1回だけ、結果を渡すのも1回だけ（連続タップで二重に回る・二重にもらうことはない）。コインは引く前に確かめる。斬った数は1体1回だけ。
- 1回 100コイン（仮）。**はじめの1回は無料**（仮）。もう持っているキャラが出たら、コインが少しもどる（N 20・R 40・SR 80・SSR 150。仮）。
- お金では回せない。そろえると別の景品が出る仕組みはない。画面にも書いた。

### 持っているキャラをサーバーにも（ログインしている人）
- 持っているキャラ・アイコン・ガチャを引いた回数を、**いつもの記録とは別の所（`saves/<sid>/extra`）**に書く（`web/head/30_account.js`）。別の端末でログインすると、読める（その端末のキャラと合わせる）。
- **Firebase のルールの変更が必要**（`firebase/database.rules.json`。前のルールは `firebase/database.rules.previous.json`）。変更は `saves/$sid` に `extra` を足しただけ。ルールを変えるまでは、extra の書きこみだけ断られ、**いつもの記録（コイン・勝ち数など）は今までどおり保存される**（別々に書くので）。

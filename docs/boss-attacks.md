# ボス（鬼）の攻撃の一覧（版63時点。数値は仮）

数値は `data/boss_attacks.json`。時間は「速さ1.5倍」をかけたあとの秒（実際のゲームの秒）。ダメージは、そのままの値（版59から、剣士の体力は150）。
下の表は `python3 tools/attack_table.py` で作り直せる（数値を変えたら、作り直してここに貼る）。

## 流れ（版57から）
- 体力は2段階：**第1形態** 4000 → 0 になると倒れる（約3.4秒。無敵・攻撃しない）→ **覚醒** して、別の体力 4000（満タンまで増える表示）→ 0 で勝ち
- 攻撃の順番は決めない。使える攻撃の中から**重み付きのくじ**で選ぶ（`scripts/combat/boss_ai.gd`）
  - 形態ごとの重み・ねらう人までの距離（範囲の外なら重み0.3倍）・使ったあと待つ秒・同じ攻撃が続くと0.4倍・強い攻撃が2回続くと0.25倍
  - 必殺技は覚醒のときだけ。覚醒して8秒たってから、必殺技どうしは24秒あける
  - 使える物がなければ、代わり（平常：横振り、覚醒：しっぽ回し）。止まらない
- 版61：**大きな手・台風・火祭りは削除**（AI は選ばない。定義はデータに残している）。**酒だまりは、どの攻撃でも残さない**（`puddles_enabled: false`）。つかみは、近いとき（範囲の中）だけ重み1.5倍。覚醒のオーラは消して、肌の色の変化だけ
- 版60：予告の見た目。ふつうの攻撃＝オレンジの円・帯（しま模様・明るい縁・広がる線）、巨大酒瓶ライドの道＝ピンクの帯＋流れる「＞」（`shaders/warning_zone.gdshader`）
- 当たると、強さに合わせてふっ飛ぶ（押しもどし kb_light／ふっ飛んで転ぶ kb_heavy／たたきつけ kb_slam／はね飛ばし kb_launch）。ヒットストップと画面のゆれつき。起き上がったあと0.6秒は、続けてふっ飛ばない（はめられない）

## 攻撃ごとの動き（短く）
- **横振り**：右うしろから左前へ、腰の高さでなぎはらう。ときどきフェイント（一度ふりかけてやめ、少しおくれて本当に振る）
- **縦振り＋衝撃波**：頭の上から地面へたたきつけ、その先へ衝撃波が走る（衝撃波はジャンプでよけられる）
- **回転斬り**：バットを横にのばして回る。最後にバットを地面に突き立てて、すき
- **しっぽ回し**：しゃがんで、しっぽで1回転（ボスのすぐそばは安全）
- **歩きながら振る**：前へ歩きながら3回振る
- **つかみ投げ**：つかまれたら「にげる」を10回。1〜3秒で逃げられないと、遠くへ投げられる。つかみそこねると、よろけてすき
- **前方突き**：うしろへ引いてから、前へまっすぐ突く（細長い範囲）。突いたあと、すき
- **バット投げ**：ふりかぶって投げ、まっすぐ飛んで、もどってくる（行きと帰りで1回ずつ当たる）。飛んでいる間、手にバットはない
- **回転突進**：しゃがんでバットを横へ → 回りながら走る（少し曲がる）→ 止まって、ふらふら（すき）
- **ジャンプ落下**：しゃがむ → 跳ぶ（落ちる所に印と影）→ 着地で直撃＋広がる衝撃波（衝撃波はジャンプでよけられる）→ しゃがみこむ（すき）
- **移動ジャンプ落下**（版62）：しゃがむ → 空中を移動して（4〜10m）、ねらう人のまわりの少しずれた所へ落ちる（落ちる所にオレンジの円）→ 直撃18だけ（衝撃波なし）→ すき
- **回転バット移動**（版62）：腕を横にのばし、体ごとぐるぐる回りながら、ねらう人のほうへまっすぐ進む。**予告なし**。バットの先（7.6m）までの丸に当たる。9ダメージ、同じ人へは0.5秒ごと・最大3回。回転突進（しゃがんでため・予告あり・曲がって走る・はね飛ばし）とは別
- **酒瓶落とし**（覚醒）：一升瓶を下から放り投げる → 放物線で落ちる（落ちる所に印）→ 割れる（酒だまりは残さない）
- **巨大酒瓶ライド**（覚醒・必殺。版63で作り直し）：空へ跳んで消える → 巨大な一升瓶（胴の半径1.9m・長さ14.4m）に**またがって座り**、ステージの外から反対の外まで**4〜6回**突っこむ。向きは**8方向**（左右・上下・ななめ）から毎回えらぶ（前と同じ向き・真逆の向きは続けない）。速さは前の0.75倍（36 m/秒前後）。1回1.5〜2.7秒、全体で約12〜19秒。走る前から通り抜けるまで、ピンクの帯＋矢印で道を予告。瓶に当たると22ダメージで、走る向きにはね飛ばされる。突入1回に**酒瓶を5本**投げる（落ちる所にオレンジの円、1本12ダメージ、道からはなれた所・おたがい4m以上はなす）。最後は空から降りてきて、1.4秒しゃがみこむ（すき）。ライドの間は、ハイライトに入れない
- **酒の大雨**（覚醒・必殺）：前からある必殺技
- 削除（版61）：大きな手・台風・火祭り

## よけ方のまとめ
- 帯（縦振り・突き・ライド）は横へ。輪（つかみ・酒瓶）は外へ。扇（横振り）はうしろか、振り終わりの先へ
- ジャンプでよけられるのは：横振り、回転斬り・しっぽ回し・回転バット移動の1回ごと、衝撃波（縦振り・ジャンプ落下）

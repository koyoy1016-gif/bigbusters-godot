# ボス（鬼）の攻撃の一覧（版56時点。数値は仮）

数値は `data/boss_attacks.json`。時間は「速さ1.5倍」をかけたあとの秒（実際のゲームの秒）。ダメージは、プレイヤーの体力100に対しての値。
全員の画面で、同じ攻撃が同じ時刻に出る（戦いが始まってからの秒で決まる）。

## 流れ
- 戦いが始まって3秒後に、最初の攻撃。攻撃と攻撃の間は0.6秒（その間も、次にねらう人のほうへ歩く。近ければ回りこむ）
- ねらう人は、攻撃ごとに順番に変わる（p1 → p2 → …）。攻撃の始めは、ねらう人へ歩きながら向きを合わせ、そのあと向きと場所を固定する
- **平常時**の順番：横振り → つかみ → 縦振り → しっぽ回し → 歩きながら振る → 回転斬り → （くり返し）
- 体力60%で、よろけて倒れる（約3.4秒。この間は攻撃しない）。起き上がると**覚醒**（赤い肌・オーラ・バットを捨てて一升瓶）
- **覚醒時**の順番：酒の雨 → つかみ → 台風 → しっぽ回し → （くり返し）。戦いが始まって45秒以降は、40秒ごとに**必殺技**（酒の大雨と大きな手を交互）

## 必殺技（覚醒のあと、45秒から40秒ごと）
| 攻撃 | 長さ | 予告 | 当たる範囲 | ダメージ | よけ方 |
|---|---|---|---|---|---|
| 酒の大雨 | 6.67秒 | 各0.67秒 | 両腕を上げて空へ酒をまき、戦場全体に40粒が次々に降る（輪：半径1.6m） | 18（1粒） | 輪から出つづける |
| 大きな手 | 6.67秒 | 各0.93秒（帯） | 大きな手が、端から端へ3回走る（帯：幅3.4m。左右交互） | 35 | ジャンプ、帯の外へ |

## 使っていない攻撃
- チラシ（扇の形に紙が飛ぶ）：覚醒の「酒の雨」に置きかえた。データとしては残っている（`flyers`）

## 動きと範囲を合わせるしくみ
- 攻撃の動きは、攻撃が始まってからの秒で決まる（`scripts/boss/boss_moves.gd`）。予告・当たりの時刻と、振る瞬間が合う
- 範囲は、バット・しっぽの先の位置を測って決めた（`tools/measure_reach.gd`、`tools/trace_tip.gd`）。`tests/test_boss_reach.gd` が、当たっている間に先が範囲の中にあるかを確かめる

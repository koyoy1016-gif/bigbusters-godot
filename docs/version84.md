# 版84：倒れた仲間の蘇生（2026-10-20）

指示書「既存ゲームの全面改善…」の15章。蘇生の時間は 20秒（ユーザー決定。前の指示の30秒ではなく、新しい指示書の20秒）。起こせるのは、味方ならだれでも（ユーザー決定。AIも起こしに来る）。

## 1. できたこと
- **倒れた瞬間**、倒れた所の床に、蘇生の範囲の輪が出る（`shaders/revive_zone.gdshader`）：**白いふち・うすい半透明の中・ななめのしま（ゆっくり流れる）**。大きさは、プレイヤーの当たりの大きさ（player_size）× 2.3 ＝ 半径 2.3m。出る時は、少し大きく出てから合う。
- 輪の外側に**緑の弧＝起こす進み**、内側に**白い弧＝のこり時間**。上に「のこり秒」の大きな字（起こしている間は「ふっかつ 1.7」）。のこり5秒からは点めつして、字が赤くなる。
- **20秒以内**に、生きている味方が輪の中に**4秒続けて**いれば、**体力30%**で起きる（緑と白の光の柱・広がる輪・のぼる光・音）。起きた直後の1.5秒は、ボスの攻撃が当たらない。
- 輪から出ると、進みは0にもどる。何人で入っても、進む速さは同じ。20秒すぎたら、輪は消えて、もう起こせない。
- 1人に輪は1つ。起きたら輪は消えるので、2回起きない。回復の膜やエンジェルの必殺技など、ほかの方法で起きた時も、輪は消える。
- **自分が倒れた時**：画面に「なかまが そばに 4びょう いれば ふっかつ（あと 15 びょう）」、起こしてもらっている間は「ふっかつ まで 2.3 びょう」。
- **AIの味方**：輪ごとに、いちばん近い1人が起こしに行って、中で待つ（その間は攻撃しない。ボスの攻撃をよける方が先）。自分もAIの味方を起こせる。
- 全員が倒れたら、今までどおり負け。
- 数値は `data/prototype_stick.json` の `revive`（window_sec 20・hold_sec 4・hp_ratio 0.3・radius_factor 2.3・guard_sec 1.5・blink_sec 5）。決まりは `scripts/combat/revive.gd`、戦いの中の見た目とつなぎは `scripts/prototype/battle_revive.gd`。

## 5. 作り方の決まり（版79で分かったこと）

### 動き（`tools/make_char_actions.py` の `pose_anim`）
- 腕・脚の向きは「**その側の外が +x**」で書く（左は +X、右は −X が外）。前が +z、上が +y。`own()` がモデルの向きに直す。
- 胸のひねり（`spine` ＝ spine03 の [前へ倒す, ひねり, 横へ倒す] 度）：**ひねりの y が＋だと右肩が前**、−だと左肩が前（版79で写真で確かめた）。左ジャブ・左手で投げる・弓は −、右ストレート・棍棒・右手で投げるは＋。横へ倒す z が＋だと、キャラの右へ倒れる。
- 腰の高さは自動（低いほうの足首が床）。`lift` は「さらに上げる量」（脚の長さ＝1。うく・跳ぶ）。`plant="L"/"R"` で片足だけ床（けり）。`air=True` で決めない（跳ぶ）。跳ぶ高さそのものは、技の `path` の h（`player.position.y`）で出す。
- 確かめ方：
  - `bash tools/moves_sheet.sh キャラのid 動きの頭 出力.jpg -50`（4つの技を7コマずつ）
  - `godot --headless --path . --script res://tools/check_feet.gd -- キャラのid 動き1,動き2 コマ数`（足首の高さ。[左 右] が 0 なら床）
  - 試しの動きは、JSON（{名前: spec}）を作って `EXTRA_ANIMS=ファイル` で `shot_anim.gd`・`check_feet.gd` に渡せる
  - 戦いの中の写真：`xvfb-run ... --script res://tools/shot_skill.gd -- 出力.png キャラのid 技 秒`（赤い照準つき）
- 写真の1コマめが、静止の姿勢（Aポーズ）で写ることがある（写す道具のくせ。ゲームでは起きない）。

### 変えた後の手順
1. 技・動きを変えた → `python3 tools/make_char_actions.py` → `python3 tools/make_looks.py`（characters.json に動きを書く）
2. 見た目（形）を変えた → `python3 tools/make_looks.py` → `xvfb-run ... tools/bake_looks.gd`（全員、または `-- キャラのid`）
3. 小物を変えた → `python3 tools/make_props.py`
4. テスト（関係する物 → 全部）

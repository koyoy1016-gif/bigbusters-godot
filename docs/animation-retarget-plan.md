# 本物のアニメ集（Quaternius Universal Animation Library）への差し替え計画

## 入手（あなたの作業。PCで。1回だけ）
1. https://quaternius.itch.io/universal-animation-library を開く
2. **Standard（無料。15MB。「Name your own price」なので 0 円でよい）** をダウンロード（クリックすると、金額の入力が出る。0 と入れて、ダウンロードへ）
3. ファイルの種類は **Godot用／GLB** を選ぶ（ZIPの中に、GLBがある）
4. ZIPをそのまま、このチャットに添付する

ページの記載（2026-10-19に確認）：CC0（個人・教育・商用で自由）、無料版は45個のアニメ、GLB書き出しがあり、Godotで使える、「Made with Godot」のタグ付き、リターゲット（ほかの骨組みに合わせる）を前提にしている。骨の名前の一覧は、ページには書いていない（**未確認**。ファイルを見て決める）。

## 私がやること（添付を受け取ってから）
1. ZIPを、中身の分からないファイルとして扱い、専用の空のフォルダに展開して、骨の名前とアニメの名前を読む
2. 剣士（MPFBの骨）と、アニメ集の骨を、Godotの標準の人型（`SkeletonProfileHumanoid`）の BoneMap で対応づける（対応表は `data/` に置く）
3. 使うアニメを選ぶ：待ち・走る・ジャンプ・こうげき（剣）・たおれる・（余裕があれば）やられた、勝った、など
4. 剣士に、本物のアニメを適用し、いまのコードの動き（`procedural_anims.gd`）は、アニメ集のないキャラ用に残す
5. 見た目を画像で確認し、`assets/LICENSES.md` に「Quaternius Universal Animation Library（CC0）」を記録する（ページのURLと確認日つき）
6. ほかのキャラ（9人のうち8人）が、モデルを持ったときも、同じ BoneMap で同じアニメが使える形にする

## 注意
- 面の数：ファイルの大きさ（ダウンロード合計100MB未満の目標）を守るため、使うアニメだけを取り出して、1つの小さなファイルにする
- 剣の持ち方は、いまの手首の補正（`wrist_cancel`）と別に、本物のアニメの手の向きに合わせて、`data/attachments.json` の `aim` を調整する

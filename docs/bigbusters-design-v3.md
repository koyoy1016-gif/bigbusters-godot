# BIGバスターズ 仕様書 v3（決定事項）

2026-10-18 決定。優先2「ゲーム仕様の再設計」の結果。
以前の仕様（`docs/bigbusters-spec-v2.md`）より、ここに書いたことを優先する。

## 1. 決定した5つ

| 項目 | 決定 | 補足 |
|---|---|---|
| a) 遊びの核 | 4人で協力して、大型の妖怪を倒す | 仲間と息を合わせて倒す達成感を中心にする |
| b) 1回の長さ | 5〜10分 | スマホで気軽に遊べる長さ。通信が途切れにくい長さにもなる |
| c) 役割分担 | 4つの役割 | 役割ごとに、得意な動きを持つ。役割の中身（名前と動き）は次の工程で決める |
| d) 無料の体験版 | 1ステージ・1体の妖怪 | 全ステージの解放は、アプリ2の買い切りで行う |
| e) 操作方法 | 横画面。左にスティック、右にボタン | 両手の親指で動かす、一般的な形 |

## 2. 前提（変えない）

- 対象：スマホのブラウザ（iPhone Safari、Android Chrome）。横画面。
- 人数：4人まで（通信の枠は p1〜p4）。
- 2つのアプリ：アプリ1（友達用、通信あり）、アプリ2（1人＋AI3人、通信なし、無料体験＋買い切り）。土台は1つのプロジェクトで共通。
- 通信：Firebase（無料枠）のみ。有料のサーバーは使わない。

## 3. まだ決めていないこと（次の工程で決める）

- 4つの役割の名前と、それぞれの動き
- 妖怪の数と、1体ごとの動き（1体目は仮）
- 勝ち負けの条件（倒せば勝ち、時間切れで負け など）
- 画面の見え方（カメラ、HPの表示）
- 役割・妖怪の数値の置き場所（`data/` のJSON。ルール3）

## 4. 次の工程

優先3「試作」へ進む。最初の試作は、次の順にする。
1. 横画面で、スティックとボタンが動く（1人）
2. 3Dの箱（仮の妖怪）を1体置き、攻撃が当たる
3. 4人の通信に、動きを乗せる（既存の箱の同期を使う）

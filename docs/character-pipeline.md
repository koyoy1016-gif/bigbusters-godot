# キャラクター（忍者）の3Dモデルを作る進め方（検討 2026-10-18）

目標：リアルで精巧な忍者（7〜8等身、腰が細い、剣を振る）。味方40体・ボス7体・敵20体の「設計上の数」。同時に出るのは、味方4＋ボス1＋サブ敵10〜15。
面の数の予算（暫定。iPhoneの負荷試験の結果）：味方 約15k面、サブ敵 約5k、ボス 約30k。本物のモデルで測り直す。

## 前提（調べて分かったこと）
- この作業環境では、Blender もその Python（bpy）も入れられない（pip が外部に出られない）。モデルの制作は、ユーザーのWindows PCで行う必要がある。
- ゲームに入れる形式は glTF（.glb）が基本。Godot が読める。ブラウザ版でも使える（骨つき）。
- 作ったモデルは `assets/` に入れ、ライセンスを `assets/LICENSES.md` に記録する（ルール5）。このリポジトリは公開なので、再配布を禁じる素材は入れられない。

## 素材の候補とライセンス（確認済み）
| 候補 | 内容 | ライセンス | 使えるか |
|---|---|---|---|
| Quaternius「Universal Animation Library」 | 120以上のアニメ（歩く・走る・攻撃など）。共通の人型の骨。glTF/FBX | CC0（商用可）。無料版は全体の6〜7割 | ◎ アニメの土台に使える |
| MakeHuman 1.2 | 人体を作るソフト（無料）。書き出したモデルは、元がCC0のものだけで構成されるので CC0 | CC0（個別の素材に AGPL が残る場合があるため、素材ごとに確認が必要） | ○ リアルな体の土台。体型を7〜8等身に調整できる（要確認）。PCで操作 |
| Mixamo（Adobe） | 自動で骨を入れる・アニメが豊富。ゲームへの商用利用は可 | 「元のキャラ・アニメのファイル（raw）の再配布は禁止」。公開リポジトリに入れると、これに当たる恐れ。2022年の文面なので現在の規約は要確認 | △ 公開リポジトリには入れない。使うなら非公開の場所が必要 |
| VRoid Studio | アニメ調の人物が作れる無料ソフト | モデルごとの条件（商用は設定による）。アニメ調で、リアル路線ではない | △ リアル路線には合わない |

## 進め方の案（おすすめ順）
- **案A（おすすめ）：土台はCC0だけで作る**
  1. 体：MakeHuman で、忍者向けの体型（7〜8等身、腰が細い）を作り、glTFで書き出す（ユーザーのPC）。
  2. 衣装・剣・頭巾：Blender（無料）で作る。Claudeが、Blender用のスクリプト（Python）を書く。ユーザーは、PCでそれを実行して、結果を渡す。
  3. アニメ：Quaternius の共通の骨に合わせる（CC0）。
  - 長所：全部CC0なので、公開リポジトリに入れられる。短所：PC作業が要る。リアルさは、衣装の作り込みしだい。
- **案B：Claude がゼロから、コードで人型を作る**（いまの試験用の人型の延長）
  - 長所：PCで何もしなくてよい。短所：リアル・精巧にはならない（筒と球の組み合わせ）。
- **案C：Mixamo を使う**
  - 長所：アニメが豊富。短所：公開リポジトリに入れられない。規約の再確認も必要。

## Claude がいまできること（ユーザーのPC作業なしで）
1. キャラクターを「データ」で増やせる仕組み：`data/characters.json`（名前・役割・モデルのファイル・面の数の予算・アニメ名の対応）。モデルがなければ、いまの箱で出る。
2. glTF のキャラを読み込んで、骨つきで出す仕組み（読み込み→アニメの対応：待つ・走る・跳ぶ・攻撃・ダウン）。試験用の人型で、テストする。
3. 本物のモデルが入ったときの、面の数・読み込みの重さの測定の道具。

## ユーザーに聞くこと
- Windows PC に、Blender と MakeHuman を入れて作業できるか（無料。手順は Claude が書く）。
- リアル路線を優先するか、アニメ調でもよいか。
- 最初に作るキャラは、主人公の忍者1体でよいか。

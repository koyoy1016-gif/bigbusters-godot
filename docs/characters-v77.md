# 味方8人の3Dキャラ（版77・2026-10-20）

ユーザーの指示書「8キャラクター統合仕様・戦闘バランス・正規分布型クリティカル・高精度3Dキャラクター制作」と、8枚の参考画像（`docs/ref/chars/IMG_*.jpeg`）から作った。
ユーザーの言葉：「コードの整理のあと、1キャラずつ生成」「自然なアニメーションもつけて、剣士のように全てのキャラ使えるように」。

## 1. 作業環境で分かったこと（大事）

- **Blender は使えない**。この作業環境から blender.org と PyPI（bpy）への通信が止められている（403）。スクリプトを書いて Blender で回すこともできない。
- そのため、**剣士と同じ体（MakeHuman の CC0 の体）と骨（137本）を土台にして、Godot の中で形を作った**。
  - 骨が剣士と同じなので、いまの動き（`assets/anims/hero_ual.res`。Quaternius UAL、CC0）がそのまま使える。
  - 新しい素材（外のモデル・画像）は使っていない。ライセンスは剣士の体と同じ。
- 確認画像は、画面のない作業機で「仮の画面（xvfb）」を使って Godot で撮った。

## 2. しくみ

| ファイル | 中身 |
|---|---|
| `scripts/characters/body_builder.gd` | 見た目を作る道具。①体格（骨のまわりの太さ、頭の大きさ）②塗り（体の面を部位・高さ・向きで選んで服の色に。しま・ひし形も）③重ね着（体の面を外へ出した、もう1枚の服。骨についていく）④部品（帽子・武器・盾・羽など。loft・tube・rod・box・sphere・torus・extrude） |
| `tools/make_looks.py` | 8人の見た目を、参考画像を見て書いた形のデータ（`data/character_looks.json`）にする。キャラの一覧（`data/characters.json`）の model・動き・動きの速さも書く |
| `tools/bake_looks.gd` | 見た目を前もって作り、`assets/models/chars/<id>.scn`（ゲーム用。遠くで軽い形に切りかわる LOD つき）と `exports/<id>.glb`（ほかのソフト用。リポジトリには入れない）に保存する |
| `tools/shot_look.gd` | 参考画像と同じ8方向（①正面〜⑧左前）を1枚に撮る |
| `tools/compare_look.py` | 参考画像（上）と、作った形（下）を並べる → `docs/ref/chars/<id>_compare.jpg` |
| `tools/measure_look.gd` | 体の高さごとの幅・奥行きを測る（部品の位置を決めるため） |
| `tests/test_character_looks.gd` | データの決まり・左右反対・形が作れる・骨が剣士と同じ・強さを変えていない、など |

作り直す手順：

```
python3 tools/make_looks.py
xvfb-run -a godot --rendering-driver opengl3 --path . --script res://tools/bake_looks.gd
xvfb-run -a godot --rendering-driver opengl3 --path . --script res://tools/shot_look.gd -- brawler /tmp/brawler.png idle 0.4
```

体の面について：もとの体（MakeHuman の書き出し）は、服の下（胴・脚・足）が消されている。そのため、Tシャツ・ズボン・くつの形を「体の面」として塗って使っている（肌にも服にもなる）。

## 4. 参考画像との差（正直な評価）

- **全員の顔は、剣士と同じ男性の顔**（MakeHuman の体を土台にしたため）。魔法使い・エンジェルは頭を大きくし、髪・帽子で囲んだが、**女の子の顔・アニメ風の大きな目にはなっていない**。いちばん大きな差。
- 体の形：腕・脚の太さ・胸の厚みは変えたが、**脚の長さ・等身（頭身）は変えていない**（アーマーのずんぐり感、エンジェルの頭身は届かない）。ファイターの腹筋・筋肉のもり上がりの形はない（太さだけ）。
- 色は単色の面（模様は、しま・ひし形・線だけ）。参考画像の質感（革のしわ・布のひだ・金の彫刻・ライオンの顔・星のししゅう）は再現していない。
- しまや線は、体の三角形の単位で塗るので、ふちがギザギザ。
- スカート・マント・髪は骨1本に固く付いている。**ゆれない**。走ると脚がスカートからはみ出すことがある。
- 参考画像の「持ち方」（ぬいぐるみをだく腕、弓を持つ手、ファイターの構え）は、動きを剣士と同じにしているため、ずれる（物は胸・手首に付けた）。
- 参考画像が8方向あるので、背面・側面も画像に合わせて作った。推測で足した物は少ない（ボンバーの背中の袋の位置、ガンナーの背中の箱など）。

## 5. 動き（「自然なアニメーション」）

- 骨が剣士と同じなので、待ち・走り・ジャンプ・攻撃・ダメージ・ころがり・たおれる、が全員そのまま動く。
- キャラごとに攻撃の動きを選んだ（3章の表）。スピードファイターは走りに「Sprint」（全力の走り）。
- 走りの動きの速さを、移動の速さに合わせた（足がすべって見えないように）：剣士の 7.0m/秒で1.1倍を基準に、移動の速さと体の大きさで計算（`characters.json` の anim_speeds）。
- 重いアーマーは待ちの動きをゆっくり（0.8倍）、攻撃もゆっくり（1.3倍）。スピードファイターは速く（1.25倍・2.2倍）。
- **未対応**：髪・マント・スカートのゆれ、キャラ専用の新しい動き（20連パンチの動き、投げる動き、弓を引く動きなど）。新しい動きの素材は、この環境では作れない（剣士の必殺技と同じ「時間を変えて作る」方法は使える）。

## 6. 「剣士のように使える」ようにしたこと

- 8人とも、`data/characters.json` の model が前もって作った形（`assets/models/chars/<id>.scn`）を指す。キャラを選ぶ画面で選ぶと、自分のキャラとしてモデルで出る。攻撃4つ（通常・Y・X・必殺）は全キャラ共通の作りなので、そのまま使える。
- AIの味方（いまの初期は アーマー・ガンナー・魔法使い）も、箱ではなくモデルで出るようになった。
- 強さの数値（体力・攻撃力・速さ・待ち時間・届く距離）は**変えていない**（テストで確認）。剣士の数値・見た目も変えていない。

## 7. 指示書のうち、やっていないこと

- 第1部の「既存の8キャラクター統合仕様書の全文」は、**リポジトリにも、今回の添付にもなかった**（20連パンチ・ダブルビーム・時間停止などの技の仕様が見つからない）。そのため、技の構成・攻撃回数の変更はしていない。
- 第2〜5部（剣士を基準にしたバランス表、正規分布のダメージの変動とクリティカル、100万回の検証）と第7部（技と当たりのフレームの対応）は、**まだ作っていない**。ユーザーの指示が「コードの整理 → 1キャラずつの生成」だったため、キャラの見た目を先にした。次に進めるなら、統合仕様書の全文が要る。
- 第6部のうち Blender でのモデル作成・ウェイトペイント・.blend の保存：Blender が使えないため、していない（2章のしくみで代わりに作った）。

## 8. 重さ（未確認・要注意）

- 1人 約3万〜3.6万の三角形（剣士も約2.9万）。予算（味方1万5千）の2倍以上。戦いに4人出ると約13万。**iPhone で重くないか、未確認**。遠くで軽い形（LOD）に切りかえる処理（ImporterMesh.generate_lods）を通したが、実際に軽い形ができて切りかわっているかは未確認。
- 形は前もって作って保存したので、ゲームの中で作る時間はかからない（作ると1人 約0.8秒かかっていた）。
- 形のファイルは1人 約0.9MB（8人で約7MB）。

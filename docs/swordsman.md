# 忍者風の剣士（けんし）の戦闘仕様（版74時点）

ゲームの中で使っている数値から書き出した一覧。数値を変えたら、ここも直す。
元のデータ：`data/characters.json` の `hero_swordsman`、キャラを選ばないときは `data/prototype_stick.json` の `roles.p1`（同じ値にそろえる）、攻撃は `data/actions.json`。

## 基本
| 項目 | 値 | 元 |
|---|---|---|
| キャラクター名 | 忍者風の剣士（データの名前は「けんし」、id は `hero_swordsman`） | characters.json |
| 役 | ファイター（近接） | characters.json |
| 体力（HP） | **190**（版70で 288.75 から変更） | characters.json・roles.p1 |
| 攻撃力 | 22.5 | 同上 |
| 攻撃が届く距離（基本） | 2.0 m（＋ボスの体の半径 2.6 m） | 同上 |
| 走る速さ | 7.0 m/秒 | 同上 |

- ダメージ ＝ 攻撃力 22.5 × 攻撃の倍率（`scripts/combat/damage.gd` の `damage_amount` だけで計算。attack_multiplier は 1.0）
- 届く距離 ＝ 2.0 m × 攻撃の範囲の倍率（`hit_area.gd` の `reach_of`）。ボスには、ボスの体の表面までの距離で当たる
- 体力の表示は切り上げ（190／190）。0 になると倒れる（ダウン）

## 攻撃パターン（4種類）
攻撃の種類は **4つ**（ボタン3つ＋必殺技）。存在しない攻撃は書いていない。

| # | 名前 | ボタン | 動き | 範囲（ボスまで） | 当たる時刻 | 連撃数（当たる回数） | 1回のダメージ | 合計ダメージ | 待ち時間 |
|---|---|---|---|---|---|---|---|---|---|
| 1 | 単純斬り | 斬り（通常） | その場で1回斬る | 2.0 m | 押してすぐ（0.0秒） | 1 | 22.5 | 22.5 | 0.35 秒 |
| 2 | かわし斬り | かわし（**Y**） | ボスへ跳びながら斬り（前へ2.0m・高さ2.0m）、少し下がって着地。1.0秒 | 3.2 m（×1.6） | 0.42 秒 | 1 | 58.5（×2.6） | 58.5 | 4.0 秒 |
| 3 | 五段斬り | 五段（X） | 素早く5回斬りながら、少しずつ前へ（1.6m）。1.5秒 | 2.6 m（×1.3） | 0.15・0.36・0.57・0.78・0.99 秒 | 5 | 18.0（×0.8） | 90.0 | 6.0 秒 |
| 4 | 切り捨て御免（必殺技） | 必殺 | 剣を構え → 力をためる → 前へ一気に約10m駆けぬける（ボスをすりぬける）→ 振り下ろして斬り捨てる → 止まって構え直す。1.5秒。動いている間は無敵 | 4.8 m（×2.4）。駆けぬけた道のどこかから届けば当たる | 0.70 秒 | 1 | 346.5（×22×0.7） | 346.5 | ゲージ |

- **攻撃数のまとめ**：攻撃の種類 4つ。1回使ったときに当たる回数は、単純斬り 1・かわし斬り 1・五段斬り 5・必殺技 1（4つ全部で 8回）
- 待ち時間：単純斬りはキャラの `attack_cooldown_sec`（0.35秒）を使う（actions.json の 0.4 ではない）
- かわし斬り・五段斬り・必殺技は、ボスのほうを向いて出る。ボスにめりこまない所で止まる
- 必殺技のダメージ（版74）：剣士だけ0.7倍（`ultimate_scale`）。495 → 346.5
- 必殺技のゲージ（版74）：ボスに与えたダメージ × 0.6667 × 1.3（剣士だけ `gauge_rate` 1.3＝30%速い）がたまり、700 でいっぱい（約808ダメージ分。前は約1050）。使うと 0 にもどる。使うと画面に技名が出る

## 回避（Y：かわし斬り）
- 版114：押してから **0〜0.3秒**（出始め）に当たる攻撃は、どれも受けない＝**回避成功**（水色の輪・光・「回避！」）。全キャラの Y が同じ（キャラの Y の技＋出始めの回避）
- 空中にいる間（跳んでいる間）は、**ジャンプでよけられる攻撃**（予告に「jumpable」の印がある攻撃）も受けない
- 待ち時間 4.0 秒（続けて押しても、ずっと無敵にはならない）。数値は `data/actions.json` の `sub`（`i_window`・`cooldown_sec`）
- AIの味方も同じボタン（Y）を使う（版71）。ボスのいまの攻撃を約2秒先まで調べ、自分の場所に当たる物があるとき：
  - Y の出始め（0〜0.3秒）に全部当たるなら、どの攻撃でも Y でよける。跳んでいる間（約0.16〜0.78秒）に当たる物は、ジャンプでよけられる攻撃なら Y でよける
  - 走って外へ出られるなら走る（両方できるときは半々）。Y にはまだ早いなら、ちょうどよい時刻まで待って Y
  - 当たる物がなければ、次に危なくなるまでの秒（すき）の中で終わる攻撃だけを使う（すきが長いと五段斬り）
  - 体力が35%より少ないとき・当たった直後1.5秒は用心し、すきが短ければ届かない所で待つ
  - 数値は `data/ai_allies.json` の `tactics`、判断は `scripts/combat/ai_ally.gd` の `_think`

## 必殺技の動き（版72）
| 秒 | すること | 見た目 |
|---|---|---|
| 0〜0.25 | 剣を上に構える（少し下がる） | |
| 0.25〜0.55 | 力をためる（剣がふるえる。前へは出ない） | 足もとに金の輪（ちぢみながら明るくなる） |
| 0.55〜0.72 | 前へ一気に約10m踏み込む（ボスがいても止まらず、すりぬける。終わりに向けて減速） | 通った道に、剣士の形の残像（2.2mごと、約5体。白く光り、0.45秒で消える） |
| 0.70 | 剣を振り下ろして斬り捨てる（当たり） | 体の前に大きな三日月の斬撃。当たると火花・一瞬止まる・画面がゆれる |
| 0.72〜1.05 | 振りぬいて、止まる | |
| 1.05〜1.5 | 剣を構え直す | |

- 向き：始めた瞬間にボスのほうを向き、その向きへ踏み込み、その向きへ斬る（向き・動き・当たりが同じ）
- 当たり（版73）：始めた所から斬る瞬間の所までの「駆けぬけた道」の、どこかから 4.8 m（＋ボスの体の半径）に届けば当たる。斬撃は、道の上でボスにいちばん近い所に出る。遠すぎると、斬撃は出るが当たらない
- 動き：`data/characters.json` の `built_anims`（Sword_Attack の時間を変えて作る。新しい素材は使わない。`scripts/characters/anim_retime.gd`）。時刻・動く道・見た目の数値は `data/actions.json` の `ultimate`、見た目は `scripts/fx/ultimate_fx.gd`
- AIの味方が使ったときも、ための輪と斬撃が出る

## つかまれたとき（版70）
- ボスのつかみ投げに当たると 8 ダメージ。1秒持ち上げられ、**必ず投げられる**（「にげる」の連打・みんなのダメージで外れる仕組みはない）
- 持ち上げられている間は、0.8秒ごとに 6 ダメージ（しめつけ）。投げられて着地で 8 ダメージ。転んでいる間は、ダメージを受けない
- 投げられた人が、ほかの人にぶつかる仕組みはない

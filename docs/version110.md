# 版110：A・X・Y・必殺のボタン・Y＝全キャラ共通の回避（2026-10-23）

ユーザーの指示書「BIGBLAST — 既存ゲーム改修・UI刷新・軽量化」を6回に分けた2回め（109名前と流れ→**110ボタンと回避**→111キャラの技→112演出→113画面の見た目→114軽量化）。

## したこと
- **ボタン**（`battle_hud.gd` の `_draw_buttons`・数値は `data/prototype_stick.json` の battle_buttons）
  - 画面の右下に2×2。4つとも同じ大きさ（縦長 140×104・横長 130×96。基準の大きさの中の値）。下の段 Y・A、上の段 X・必殺。A は親指の休む右下
  - 角ばった斜めの板（黒っぽい・ふちは自分の役職の色。Y は水色・必殺は金）。中に大きく A／X／Y／必殺、その下に小さく技の名前（長い名前は字を小さくして入れる）
  - 押すと、短く光って少しふくらむ。使えない時（待ち時間・技の最中・つかまれ中）は暗くなり、待ち時間の残りを上から暗い帯で出す。つかまれ中は字が「×」
  - 必殺：ゲージを下から色でためる。たまったら光がゆっくり明るく・暗く。使える条件・押し方（タップ・キー）は前のまま
  - 押せる場所は四角の中（ふちから 6px 外まで）。前は丸の中
- **Y＝全キャラ共通の回避**（`data/actions.json` の sub。キャラの上書き `data/char_actions.json` には sub がない）
  - スティックの向きへ（倒していなければ、ねらう敵の反対へ）約3.4m 転がる。0.55秒・待ち時間1.2秒
  - よけられる時間（はじめの 0.02〜0.34秒）に当たった攻撃は受けない＝**回避成功**：水色の輪・火花・「回避！」の字（0.6秒）・ぬける音。同じ攻撃で1回だけ
  - 転がる音は「jump」、成功の音は「free」（ボスの攻撃の予告の音 whoosh と別。同じ音は少しの間続けて鳴らないので、回避で予告の音が消えないように）
  - よけられる時間の外（転がり終わりぎわ）に当たれば、ふつうに受ける。続けて押しても、待ち時間があるので、ずっと無敵にはならない（押し続けて4秒のうち無敵は約1.3秒）
  - AI のなかまも、同じ回避を使う（ジャンプでよけられない攻撃も、よけられる時間の中なら、よけられる）
- **今の Y の技は、X と比べて良い方を X に残した**（ユーザー決定。くわしくは `docs/char-actions-v110.md`）
  - 剣士：X 五段斬り（Y かわし斬り → 回避に）／拳士：X 20連パンチ（版111で10連に）／瞬：X バニッシュ（Y から X へ。超高速モードはボタンから外した）／銃士：X ダブル連射／奇術師：X びっくりプレゼント／魔法師：X チャージ魔法（時間停止は外した：通信中に効かないため）／守護士：X シールドドーム／兵隊：X 兵隊よ、進め！（版111で小隊召集に）／介護士：X いやしのドーム（回復の弾はボタンから外した）
  - 外した技の効果のコード（speed_mode・time_stop・heal_shot）は残っている。版114で片づけを考える
- 編成の画面の技の並び：A（通常）・X（スキル）・必殺技・Y（共通）
- 体力の表示：なかまのバーの上に、役職名を役職の色で（`battle_hp_hud.gd` の `_label_of`）

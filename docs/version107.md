# 版107：通信① 相手の動きをなめらかに（2026-10-21）

ユーザー（08:43）：「通信するとカクカクだし、動きが一致しない。改善できる？」→ 3回に分ける（①相手の動きをなめらかに ②相手の技・ジャンプ・向き ③ボスを全員の画面で同じに）の①。

## 原因
- 相手の位置は 0.1 秒ごとに届くが、通信で届く間隔がばらつく（早い・遅い・2つまとめて）。
- 前は、届いた位置へ毎コマ少しずつ近づけていた（smooth_per_sec 10）。届く間隔がばらつくと、速くなったり、止まりかけたりして、カクカクに見えた。
- 走る／待つの切りかえも、この動きの速さで決めていたので、ちらついた。

## 直したこと
- 送る位置の時刻を、サーバーの時計（自分の時計＋サーバーとのずれ）にした（`web/head/10_room.js`。ルールは変えない：x, y, t のまま）。
- `scripts/network/snapshot_buffer.gd`（新規）：相手ごとに、届いた位置を「送った時刻」つきでためる。
  - 見せるのは「いまより少し前（遅れ）」の位置。となりの2つの記録の間を、時刻でなめらかにつなぐ → 送った人と同じ速さで動く。
  - 遅れ：「前の記録の送った時刻から、次の記録が届くまで」の多め（10回に9回はまにあう値）。急に変えず、1秒に 30 ms までずつ変える。
  - 記録がまにあわない時は、最後の速さで 0.12 秒分だけ先へのばし、それ以上は止める。あとで届いた記録で位置がずれたら、ぱっと飛ばさず少しずつもどす。大きく飛んだ時（3m 以上：戦いの始まりなど）は、すべらせずに飛ぶ。
  - 送った時刻がおかしい（3秒以上ずれ・古い版で時刻がない）時は、受けた時刻を使う。
- 読み方：全部の状態（体力・ダメージなど）は 0.1 秒ごと（前は 0.05）、位置だけは 0.05 秒ごとに読む（位置は前と同じく 1秒に約20回）。位置が読めなかった時は、相手を消さない。
- AI の味方（同じ画面の中）は、いままでどおり。
- 数値：`data/prototype_stick.json` の `net_interp`・`net_poll_sec`・`net_pos_poll_sec`。

## 結果（テストの中のまねた通信。PC）
届く遅れを 40〜250 ms でばらつかせ、相手が 6 m/秒で走る：
| | 前 | 版107 |
|---|---|---|
| 1コマの動きのばらつき | 57.8% | **1.4%** |
| 平均から半分以上ずれたコマ | 64／143 | **0／145** |
| 止まった時の行きすぎ | — | 0 m |
| 相手が、本当の位置より何 ms うしろに見えるか | 291 ms | 324 ms |

届く遅れが 60〜120 ms（ふつうのスマホの通信くらい）の時：ばらつき 38.4% → 0.0%、うしろ 231 → 243 ms。
- なめらかにするかわりに、相手は前より 10〜30 ms ほど遅れて見える（ずっと同じ遅れなので、カクカクはしない）。
- 全部の状態の読みこみ（文字→辞書）：1回 40 µs（PC）、位置だけ 5 µs。1秒に 20回→10回に減らした分は小さい。

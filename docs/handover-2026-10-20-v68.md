## 1. ゲームの概要
- Godot 4.7.2、GDScript、Compatibilityレンダラー、Web書き出し（スレッドなし）。
- 最優先の環境はスマホのブラウザ（iPhone Safari／Android Chrome）。縦画面を先に作り、横にも対応する。

  - アプリ1：友達用。Firebase で通信し、4桁の部屋に集まる。

- 画面の流れ：タイトル → ロビー → へんせい → 戦い → ハイライト → 報酬 → さいせん／ロビー。
- いま遊べるのは「剣士（メインキャラ、モデルあり）＋AIの味方3人（箱）」で鬼と戦う試作。

## 4. テストの回し方
- 1本ずつ：`timeout 300 /home/claude/godot/godot --headless --path . --script res://tests/test_XXX.gd`
  - 最後の「失敗: N」と、終了コードを見る。
  - 画面描画の ERROR（"Drawing is only allowed…"、"get_global_transform" など）がたくさん出るが、画面なしで動かしているせいで、問題ではない。
- 全部：
  ```
  for f in tests/test_*.gd; do n=$(basename $f); timeout 600 /home/claude/godot/godot --headless --path . --script res://tests/$n >/tmp/out_$n.txt 2>&1 || echo "FAIL $n"; done
  ```
  - いまは **Godot 51本、全部合格**。
- Node（通信のJS）：`node --test tests/js/*.test.mjs` → **59件、全部合格**。
- 注意：
  - スクリプトに文法エラーがあると、Godot は止まらずに固まる。必ず `timeout` を付ける。
  - GDScript の `:=`（型の推測）は、型の決まらない値（Variant）だとエラーになる。`var a: float = ...` のように型を書く。
  - 書式の文字列で「%」そのものを出すときは `%%` と書く。
  - 画面なしのテストでは `global_position` が 0 になることがある。top_level のノードは `.position` を使う。
  - テストで戦いを進めるときは、`combat_update(dt)` のあとに **`_pose_boss(dt)` も呼ぶ**。呼ばないと、ボスが「よろけ」から起き上がらない。
  - 数値を変えると、古いテストが固定の値で落ちる。そのたびに新しい値に直す（版66〜68で何度もあった）。

## 6. 版52〜68で決まったこと・変えたこと（古い順）
細かい記録は `NOTES.md` の「いまの状況」にある。ここでは、**いまも有効な決まり**が分かるようにまとめた。

### ボスの作り（版52〜55）
- 版52：脚に骨を入れた。攻撃を作り直した。
  - 攻撃の速さは全体で1.5倍（`boss_attacks.json` の `attack_speed`。`*_sec`・`duration` をまとめて短くする。`speed_exempt` に書いたキーは除く）。
  - ボスは攻撃の合間に、ねらう人のほうへ歩く。
  - つかむ時間は1〜3秒。
- 版53〜54：ボスを人型に作り直した。
  - 体は剣士と同じ骨のモデル（`hero_swordsman.glb`）を大きくしたもの。
  - 動きは `scripts/boss/boss_anim.gd`（動き素材の取り出し）と `boss_moves.gd`（振り付け）。
  - **攻撃の動きは、攻撃が始まってからの秒で決まる**。だから、予告・当たりの時刻と、振る瞬間がそろう。
- 版55：ボスを4倍の大きさ（身長約8m）にした。
  - 当たりの範囲を、バットの先・しっぽの先を実際に測って合わせた。**見た目と当たりは一致させる**という方針。
  - 立ち止まらず、攻撃し続ける。

### 全面改修（版57。ユーザーの指示書「Godotボス戦・全面改修 最終実装指示書」）
- **体力は2段階**（`scripts/combat/boss_phase.gd`）：平常 → 0 で倒れる（約3.4秒。無敵で攻撃しない）→ 覚醒（別の体力）→ 0 で勝ち。
- **攻撃は重み付きのくじで選ぶ**（`scripts/combat/boss_ai.gd`）。決まった順番はない。くじの決まり：
  - 形態（平常・覚醒）ごとの重み。
  - ねらう人が範囲の外なら、重みは0.3倍。
  - 使ったあとの待ち時間（`cooldown_sec`）。
  - 同じ攻撃が続くと0.4倍。強い攻撃が2回続くと0.25倍。
  - 必殺技は覚醒のときだけ。覚醒して8秒たってから出る。必殺技どうしは24秒あける。
- ふっ飛びは4種類：kb_light／kb_heavy／kb_slam／kb_launch。ヒットストップと画面のゆれがつく。起き上がって0.6秒は、続けてふっ飛ばない。
- 乱数は「戦いの開始時刻＋攻撃の番号」から作る（`Attacks.rng_for`）。通信中も、全員の画面で同じ攻撃になる。

### 味方の強さ（版58・59・66・68）
- 版58で2倍 → 版59で「元の1.5倍」になった（剣士 体力150・攻撃力18）。
- 版66：**剣士だけ**体力1.75倍（262.5）。
- 版68：**剣士だけ**体力1.1倍（288.75）、攻撃力1.25倍（22.5）。
- ほかの8人は版59のまま（6章の最後の表）。
- 剣士の値は2か所にある。**両方そろえる**：
  - `data/characters.json` の `hero_swordsman`
  - `data/prototype_stick.json` の `roles.p1`（キャラを選ばないとき）
- 体力の表示は切り上げ（289／289）。
- サブ敵（小さい紫の箱）は消してある（`sub_enemy_enabled: false`）。

### 予告とハイライト（版60）
- 攻撃の予告の見た目（`shaders/warning_zone.gdshader`、色は `boss_attacks.json` の `zone_style`）：
  - ふつうの攻撃：オレンジの半透明の面＋しま模様＋明るい縁。
  - 巨大酒瓶ライドの道：ピンクの帯＋流れる「＞」矢印。
  - 版68で `safe`（緑）を追加した。酒の大雨の安全地帯に使う。
- ハイライトは、箱ではなく本物のボスのモデルで再生する（戦いの間に、ボスの位置・向き・攻撃を記録）。ライドの間はハイライトに入れない。

### 攻撃の追加と削除（版61〜67）
- 版61：**大きな手・台風・火祭りは削除**した（AIが選ばない。データには残してある）。
  - 酒だまりは、どの攻撃でも残さない（`puddles_enabled: false`）。
  - 覚醒のオーラは消して、肌の色の変化だけにした。
- 版62：「移動ジャンプ落下」（jump_move）を追加した。
- 版63：「巨大酒瓶ライド」を作り直した（6章の「いまの攻撃」）。
- 版64：**覚醒の体力が4分の1減るたびに、必ず巨大酒瓶ライド**を入れる（残り75%・50%・25%の3回。`awake_ride_every: 0.25`）。それ以外でも、ランダムに出る。
- 版65：ライドの速さを1.2倍にした。バット投げの予告は細い線だけにした。
- 版66：**「回転バット移動」（spin_bat）を完全に削除**した（データ・コード・テストから消した。ほかの仕組みから使われていないことを確認済み）。「回転斬り」と「回転突進」は残す。
- 版67：
  - **形態ごとに、使える攻撃を最低1回は出す**。まだ出していない攻撃を先に選ぶ。待ち時間と必殺技の間かくは守る。全部出たら、ふつうのくじにもどる。
  - 消した攻撃が選ばれたら、出さずに別の攻撃に切りかえる（`is_valid`／`unused_in`）。
  - **つかみ投げの向き**：投げる瞬間に、投げられる人を除いて、ボスから**いちばん遠い人のほう**へ投げる。同じ距離なら枠の名前の順。だれもいなければボスの正面。
  - **投げられた人のぶつかり**：飛んでいる間か着地で、ほかの人（体の中心から1.6m以内・高さ4m以下）にぶつかると、次のとおりになる。
    - ぶつかった人と投げられた人の両方に8ダメージ。
    - ぶつかった人は転ぶ（kb_heavy）。
    - 1回の投げで、1人に1回だけ。
    - 転んでいる人・起き上がった直後の人・つかまれている人には当たらない。

### いまのボスの攻撃（版68）
長さ・ダメージなどの細かい数値は `docs/boss-attacks.md` の表にある。
- **平常**の攻撃（11種）：横振り、縦振り＋衝撃波、回転斬り、しっぽ回し、歩きながら振る、前方突き、バット投げ、回転突進、ジャンプ落下、移動ジャンプ落下、つかみ投げ。
- **覚醒**の攻撃（12種）：
  - ふつうの攻撃：横振り、縦振り、しっぽ回し、前方突き、バット投げ、回転突進、ジャンプ落下、移動ジャンプ落下、つかみ投げ、酒瓶落とし。
  - **必殺技**：巨大酒瓶ライド、酒の大雨。
- 巨大酒瓶ライドの動き：
  - 空へ跳び、巨大な一升瓶にまたがって、ステージの外から反対の外まで4〜6回突っこむ。
  - 向きは8方向。速さは約43 m/秒。当たると22ダメージ。
  - 突入1回に瓶を12本投げる（1本12ダメージ）。
  - 最後に降りてきて、1.4秒すきができる。
- 削除した攻撃：大きな手・台風・火祭り（版61）、回転バット移動（版66）。

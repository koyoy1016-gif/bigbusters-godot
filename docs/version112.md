# 版112：演出（必殺技の名前・敵の登場・覚醒・敵の攻撃の名前）（2026-10-23）

ユーザーの指示書「BIGBLAST — 既存ゲーム改修・UI刷新・軽量化」を6回に分けた4回め（109名前と流れ→110ボタンと回避→111キャラの技→**112演出**→113画面の見た目→114軽量化）。
数値と文字は `data/prototype_stick.json` の ult_banner・enemy_intro・awakening_fx・enemy_attack_label。攻撃の名前は `data/boss_attacks.json` の display_names。
描くのは `battle_hud.gd`（毎コマの重ね描き。字の大きさは決まった数段だけ使い、拡大・縮小で動かす＝文字の絵がふえない）。出す・消すのは `stick_prototype.gd`（show_enemy_intro・show_awakening・show_enemy_attack・update_cues）。

## したこと
- **必殺技の名前**（画面のまん中に大きく）
  - 角ばった暗い帯が、まん中から左右へのびる（0.16秒）。上下のふちに役職の色の線
  - 字：役職の色の光（太い縁取りをうすく2回）＋黒い縁取り＋白に役職の色を少し混ぜた字。下に役職名（役職の色）
  - 名前が画面に入らない時（長い名前・せまい画面）は、画面の幅の86%に入るまで字を小さくする
  - なかま（AI）の必殺技は、そのなかまの役職の色
- **敵の登場**（試合の始めに1回。2.6秒。ボスの最初の攻撃 3秒より前に終わる）
  - 「ENEMY APPROACH」（字の間をあける・はじめは点めつ）・敵の名前を大きく（右から少し入る）・役「BOSS」。赤い線が左右からのびる
  - 敵の名前は仮で「酔いどれ大鬼」（今までボスに名前がなかったので付けた。`enemy_intro.name` で変えられる）
  - 次の試合（再戦）では、また1回出る。前の試合の物は残らない
- **ボスの覚醒**（1試合に1回だけ。2.2秒）
  - 画面のふちが赤むらさきに光って脈うつ・「AWAKENING」が大きく出て落ち着く（少しゆれる）・その下に「覚醒」
  - 覚醒の条件・時（倒れて起き上がって雄たけび）は前のまま。前の「覚醒！」の字は出さない
- **敵の攻撃の名前**（右上）
  - ボスの攻撃が始まった時（予告の音と同じ時）に、右から流れて入る（0.18秒）。2.2秒で消える
  - 新しい攻撃が来たら、前の名前はすぐ入れかえる（いつも1つだけ。ためない）。同じ攻撃の間は出し直さない
  - 上に小さく「ENEMY SKILL」。ボスの必殺技（巨大酒瓶ライド・酒の大雨）は金色で「ENEMY ULTIMATE」
  - 場所：横画面はボスの体力のバーの右、たて画面はバーの下の右（なかまの体力の列と重ならない）
  - ボスが倒れたら消す
- `tools/attack_table.py` の攻撃の名前も display_names から読む（表の名前と画面の名前が同じ）
- `tools/shot_cues.gd`：演出の写真を撮る道具
